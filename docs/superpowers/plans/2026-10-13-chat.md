# Chat (Phase 2) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Turn Iris into a usable chat client for the Hermes dashboard. It lists conversations, opens a stored transcript, sends a message and streams the reply (with tool calls), stops a turn, and answers approvals and clarifying questions.

**Architecture:**
- **RPC layer.** It now hands `approval` and `clarify` server requests up instead of declining them, and it advertises `client.capabilities`.
- **Chat backend.** A `ChatBackend` seam, implemented by `DashboardChat`. It uses RPC for anything live and REST for stored history, and turns wire frames into a sealed `ChatEvent` set.
- **Chat state.** A pure, immutable `ChatState.apply(event)` reducer drives a `ChatController` (`ValueNotifier`) that each `ChatScreen` owns.
- **Home screen.** A conversation list replaces the Phase 1 link status screen as home. That screen stays reachable from the list's header.

**Tech Stack:** Flutter 3.41.6 / Dart 3.11, flutter_riverpod 3.3, dio 5.11. No new dependencies.

**Spec:** `docs/superpowers/specs/2026-10-13-chat-design.md`. It has the verified wire shapes; read it before Task 2.

## Global Constraints

- Mobile only (Android, iOS).
- **No new dependencies.** Do not edit `pubspec.yaml`.
- Nothing throws past `lib/data`. Data-layer methods return `Result<T>`; only `dispose`/`close` return `Future<void>`.
- Every wire read goes through `Json` (`lib/core/json.dart`). Never cast decoded JSON.
- **Server-request answers:**
  - Server request ids are strings (`srq-…`).
  - A single clarify question is answered with a result frame. Batch questions use `clarify.lock`.
  - An approval is answered with the `approval.respond` RPC and never with a frame.
  - A question id that Iris made up (`synthetic`) is never sent.
- **Calls go to the right session id:**
  - Live calls (`prompt.submit`, `session.interrupt`) and event filtering use the **runtime** session id.
  - History and the list use the **stored** id.
- **Code style:** follow the existing code. That means a `library;` doc comment at the top of each file, `///` docs that say *why*, single quotes, relative imports in `lib/`, `package:iris/...` imports in `test/`, sorted imports, and `const` wherever it is possible.

```dart
/// JSON-RPC over one open socket.
///
/// Deliberately thin: it correlates requests with responses, forwards events,
/// hands the server requests Iris can show to whoever presents them, and
/// declines the rest. It does not reconnect — one client lives exactly as long
/// as one socket, and `DashboardSession` replaces it when the socket dies.
library;

import 'dart:async';

import '../../core/failure.dart';
import '../../core/json.dart';
import '../../core/logging.dart';
import '../../core/result.dart';
import 'rpc_frame.dart';
import 'wire_socket.dart';

final class RpcClient {
  RpcClient(
    this._socket, {
    this.defaultTimeout = const Duration(seconds: 30),
    this.presented = const {},
  }) {
    _subscription = _socket.frames.listen(
      _onFrame,
      onError: (Object _) => _shutdown(),
      onDone: _shutdown,
      cancelOnError: true,
    );
  }

  static const _log = IrisLog('rpc');

  final WireSocket _socket;
  final Duration defaultTimeout;

  /// Server request methods Iris shows to a person, such as `approval` and
  /// `clarify`. Every other server request is declined at once.
  final Set<String> presented;
  late final StreamSubscription<String> _subscription;
  final Map<int, _Pending> _pending = {};
  final _events = StreamController<RpcEvent>.broadcast();
  final _serverRequests = StreamController<RpcServerRequest>.broadcast();
  final _closed = Completer<void>();
  int _nextId = 0;

  /// Stream events, in arrival order. Closes with the socket.
  Stream<RpcEvent> get events => _events.stream;

  /// Requests the gateway makes of Iris whose method is in [presented].
  /// Closes with the socket.
  Stream<RpcServerRequest> get serverRequests => _serverRequests.stream;

  /// Completes when the socket has closed, for whatever reason.
  Future<void> get done => _closed.future;

  bool get isOpen => !_closed.isCompleted;

  /// Calls [method]. Never throws.
  Future<Result<Json>> call(
    String method, {
    Map<String, Object?>? params,
    Duration? timeout,
  }) {
    if (!isOpen) return Future.value(Err(_closedFailure(method)));
    final id = ++_nextId;
    final completer = Completer<Result<Json>>();
    final timer = Timer(timeout ?? defaultTimeout, () {
      if (_pending.remove(id) != null) {
        completer.complete(
          Err(
            IrisFailure(
              FailureKind.timeout,
              message: 'No answer to $method in time.',
              endpoint: method,
            ),
          ),
        );
      }
    });
    _pending[id] = _Pending(method, completer, timer);
    try {
      _socket.send(RpcEncode.request(id, method, params));
    } on Object catch (error, stackTrace) {
      _pending.remove(id);
      timer.cancel();
      return Future.value(
        Err(
          IrisFailure(
            FailureKind.offline,
            endpoint: method,
            cause: error,
            stackTrace: stackTrace,
          ),
        ),
      );
    }
    _log.debug('→ $method #$id');
    return completer.future;
  }

  /// Answers server request [id] with [result]. False when the socket is
  /// already gone; the gateway then withdraws the request itself.
  bool reply(String id, Map<String, Object?> result) {
    if (!isOpen) return false;
    try {
      _socket.send(RpcEncode.resultReply(id, result));
      return true;
    } on Object {
      return false;
    }
  }

  /// Proves the socket is alive.
  ///
  /// A gateway without `ping` answers "method not found" — and that answer
  /// travelled over this socket just as a pong would.
  Future<Result<void>> ping({
    Duration timeout = const Duration(seconds: 5),
  }) async {
    final result = await call('ping', timeout: timeout);
    return switch (result) {
      Ok() => const Ok(null),
      Err(:final failure) when failure.rpcError?.isMethodNotFound ?? false =>
        const Ok(null),
      Err(:final failure) => Err(failure),
    };
  }

  void _onFrame(String text) {
    switch (RpcFrame.parse(text)) {
      case RpcResponse(:final id, :final result, :final error):
        final pending = _pending.remove(id);
        if (pending == null) {
          _log.debug('unmatched response #$id');
          return;
        }
        pending.timer.cancel();
        pending.completer.complete(
          error == null
              ? Ok(result)
              : Err(
                  IrisFailure(
                    FailureKind.rejected,
                    message: IrisLog.redact(error.message),
                    endpoint: pending.method,
                    cause: error,
                  ),
                ),
        );
      case final RpcEvent event:
        _events.add(event);
      case final RpcServerRequest request
          when presented.contains(request.method):
        _serverRequests.add(request);
      case RpcServerRequest(:final id, :final method):
        // Nothing in Iris can show this one. Declining at once makes the tool
        // fail fast instead of waiting out its deadline.
        _log.info('declined server request $method');
        _trySend(
          RpcEncode.errorReply(
            id,
            RpcCodes.methodNotFound,
            'Iris has no handler for $method',
          ),
        );
      case RpcUnreadable(:final reason):
        _log.warn('dropped frame: $reason');
    }
  }

  void _trySend(String text) {
    try {
      _socket.send(text);
    } on Object {
      // The socket is closing; the gateway withdraws the request itself.
    }
  }

  void _shutdown() {
    if (_closed.isCompleted) return;
    _closed.complete();
    for (final pending in _pending.values) {
      pending.timer.cancel();
      pending.completer.complete(Err(_closedFailure(pending.method)));
    }
    _pending.clear();
    unawaited(_events.close());
    unawaited(_serverRequests.close());
  }

  static IrisFailure _closedFailure(String method) => IrisFailure(
    FailureKind.offline,
    message: 'The live connection closed.',
    endpoint: method,
  );

  Future<void> close() async {
    await _subscription.cancel();
    await _socket.close();
    _shutdown();
  }
}

final class _Pending {
  _Pending(this.method, this.completer, this.timer);

  final String method;
  final Completer<Result<Json>> completer;
  final Timer timer;
}
```

```dart
/// Reads conversation lists and stored transcripts from the dashboard.
///
/// Shapes verified against Hermes 0.18.2 on 2026-10-13: `session.list` returns
/// `{sessions: [{id, title, preview, started_at, message_count, source}]}`,
/// and `GET /api/sessions/{id}/messages` returns `{session_id, messages,
/// pagination}` where each row has a string `content`, a `role` of `user`,
/// `assistant` or `tool`, OpenAI-style `tool_calls` on assistant rows, and
/// `tool_call_id` plus `tool_name` on tool rows. Older rows carried `content`
/// as a list of parts; both are read.
library;

import '../../core/json.dart';
import 'chat_models.dart';

abstract final class HistoryParser {
  /// The conversation list from a `session.list` result.
  static List<ConversationSummary> conversations(Json result) {
    final rows = result.isList ? result.list : result['sessions'].list;
    return [
      for (final row in rows)
        if (_conversation(row) case final conversation?) conversation,
    ];
  }

  static ConversationSummary? _conversation(Json row) {
    final id = firstText(row, const ['id', 'session_id', 'stored_session_id']);
    if (id == null) return null;
    return ConversationSummary(
      id: id,
      title:
          firstText(row, const ['title', 'preview']) ?? 'Untitled conversation',
      startedAt: row
          .any(const ['last_active', 'updated_at', 'started_at'])
          .dateTimeOrNull,
      messageCount: row['message_count'].integer(),
      source: firstText(row, const ['source']),
    );
  }

  /// A stored transcript, oldest first, from a `/messages` response body.
  static List<TranscriptItem> transcript(Json body) {
    final rows = body.isList ? body.list : body['messages'].list;
    final items = <TranscriptItem>[];
    // Tool results name the call they answer; this finds its card.
    final callAt = <String, int>{};
    for (final (index, row) in rows.indexed) {
      // Model-facing scaffolding that Hermes marks as never shown.
      if (row['display_kind'].string().trim() == 'hidden') continue;
      final id = row['id'].stringOrNull ?? 'row-$index';
      final content = contentOf(row);
      switch (row['role'].string().trim().toLowerCase()) {
        case 'user':
          if (content.trim().isNotEmpty) {
            items.add(UserTurn(id: id, text: content));
          }
        case 'assistant':
          final turn = AssistantTurn(
            id: id,
            text: content,
            reasoning: row.any(const ['reasoning', 'reasoning_content']).string(),
          );
          if (!turn.isEmpty) items.add(turn);
          for (final (n, call) in row['tool_calls'].list.indexed) {
            final callId =
                firstText(call, const ['id', 'call_id']) ?? '$id-call-$n';
            final function = call['function'];
            callAt[callId] = items.length;
            items.add(
              ToolCall(
                id: callId,
                name:
                    firstText(function, const ['name']) ??
                    firstText(call, const ['name']) ??
                    'tool',
                arguments:
                    function['arguments'].stringOrNull ??
                    call['arguments'].stringOrNull,
              ),
            );
          }
        case 'tool':
          final callId = firstText(row, const ['tool_call_id', 'call_id']);
          final at = callId == null ? null : callAt[callId];
          final matched = at == null ? null : items[at];
          if (at != null && matched is ToolCall) {
            items[at] = matched.copyWith(output: content);
          } else {
            items.add(
              ToolCall(
                id: callId ?? id,
                name: firstText(row, const ['tool_name', 'name']) ?? 'tool',
                output: content,
              ),
            );
          }
        default:
          // System prompts and roles this build does not know stay hidden.
          break;
      }
    }
    return items;
  }

  /// The visible text of a row. `display_content` wins when Hermes projected
  /// one; `content` is a string today and a list of parts on older rows.
  static String contentOf(Json row) {
    final projected = row['display_content'].stringOrNull;
    if (projected != null) return projected;
    final content = row.any(const ['content', 'text']);
    if (content.stringOrNull case final text?) return text;
    final parts = <String>[];
    for (final part in content.list) {
      final text =
          part.stringOrNull ?? part.any(const ['text', 'content']).stringOrNull;
      if (text != null && text.isNotEmpty) parts.add(text);
    }
    return parts.join('\n');
  }

  /// The first of [keys] holding non-blank text, trimmed.
  static String? firstText(Json json, List<String> keys) {
    for (final key in keys) {
      final value = json[key].stringOrNull?.trim();
      if (value != null && value.isNotEmpty) return value;
    }
    return null;
  }
}
```

```dart
///
/// The gateway's stream events and server requests are parsed here into a
/// small closed set, so the transcript logic switches over types the compiler
/// checks instead of strings. Field fallbacks follow Hermes Conduit's
/// `StreamEventParser`, which tracks every spelling Hermes has used.

import '../rpc/rpc_frame.dart';
import 'chat_models.dart';
import 'history_parser.dart';

sealed class ChatEvent {
  const ChatEvent(this.sessionId);

  /// The live session it belongs to. Empty when the gateway named none.
  final String sessionId;

  static const _toolIdKeys = ['tool_id', 'tool_call_id', 'call_id'];

  /// The chat event for a stream [event], or null for one chat does not use.
  static ChatEvent? fromEvent(RpcEvent event) {

    final payload = event.payload;
    switch (event.type) {
      case 'message.start':
        return MessageStarted(session);
      case 'message.delta':
        final delta =
            payload['text'].stringOrNull ?? event.raw['text'].stringOrNull ?? '';
        return delta.isEmpty ? null : TextDelta(session, delta);
      case 'reasoning.delta' || 'message.reasoning' || 'message.reasoning.delta':
        final thought =
            payload
                .any(const ['reasoning', 'reasoning_content', 'text', 'content'])
                .stringOrNull ??
            event.raw.any(const ['reasoning', 'text']).stringOrNull ??
            '';
        return thought.isEmpty ? null : ReasoningDelta(session, thought);
      case 'message.complete':
        return MessageCompleted(
          session,
          content: payload.any(const ['content', 'text', 'rendered']).stringOrNull,
          reasoning: payload['reasoning'].stringOrNull,
        );
      case 'tool.start' || 'tool_call':
        return ToolStarted(
          session,
          toolId: HistoryParser.firstText(payload, _toolIdKeys),
          name: HistoryParser.firstText(payload, const ['name', 'tool_name']) ?? 'tool',
          input: _text(
            payload.any(const ['args_text', 'context', 'input', 'arguments', 'args']),
          ),
        );
      case 'tool.complete' || 'tool_result':
        return ToolCompleted(
          session,
          toolId: HistoryParser.firstText(payload, _toolIdKeys),
          name: HistoryParser.firstText(payload, const ['name', 'tool_name']) ?? 'tool',
          output: _text(payload.any(const ['output', 'result'])),
          failed: payload['is_error'].boolean() || payload['error'].hasValue,
        );
      case 'error':
        return TurnFailed(
          session,
          payload['message'].stringOrNull ?? 'Hermes reported an error.',
        );
      case 'message.interrupted' || 'session.interrupted':
        return TurnInterrupted(session);
      case 'session.busy':
        return BusyChanged(session, busy: payload['busy'].boolean());
      case 'session.title':
        final title = HistoryParser.firstText(payload, const ['title']);
        return title == null ? null : TitleChanged(session, title);
      case 'approval.request':
        final approval = parseApproval(payload, session);
        return approval == null ? null : ApprovalAsked(approval);
      case 'clarify' || 'clarify.request':
        final clarify = parseClarify(payload, session);
        return clarify == null ? null : ClarifyAsked(clarify);
      case 'clarify.expire':
        final expired = HistoryParser.firstText(payload, const ['request_id', 'requestId']);
        return expired == null ? null : RequestWithdrawn(session, expired);
      case 'request.cancel':
        final cancelled = HistoryParser.firstText(payload, const ['id', 'request_id']);
        return cancelled == null ? null : RequestWithdrawn(session, cancelled);
      default:
        return null;
    }
  }

  /// The chat event for a presented server [request], or null.
  static ChatEvent? fromServerRequest(RpcServerRequest request) {
    final session = request.params['session_id'].string();
    switch (request.method) {
      case 'approval':
        final approval = parseApproval(
          request.params,
          session,
          serverRequestId: request.id,
        );
        return approval == null ? null : ApprovalAsked(approval);
      case 'clarify':
        final clarify = parseClarify(
          request.params,
          session,
          requestId: request.id,
        );
        return clarify == null ? null : ClarifyAsked(clarify);
      default:
        return null;
    }
  }

  /// An approval from an `approval.request` payload or `approval` request
  /// params. Null without a session, which nothing could answer.
  static ApprovalRequest? parseApproval(
    Json payload,
    String sessionId, {
    String? serverRequestId,
  }) {
    if (sessionId.isEmpty) return null;
    final offered = <String>[];
    for (final choice in payload['choices'].list) {
      final value = choice.stringOrNull?.trim();
      if (value != null && value.isNotEmpty && !offered.contains(value)) {
        offered.add(value);
      }
    }
    final permanent = payload['allow_permanent'].boolOrNull ?? true;
    return ApprovalRequest(
      sessionId: sessionId,
      command: HistoryParser.firstText(payload, const ['command', 'code', 'text']) ?? '',
      description:
          HistoryParser.firstText(payload, const ['description', 'message', 'prompt']) ??
          'Approval required',
      choices: offered.isNotEmpty
          ? offered
          : ['once', 'session', if (permanent) 'always', 'deny'],
      queueId: HistoryParser.firstText(payload, const ['request_id', 'requestId']),
      serverRequestId: serverRequestId,
    );
  }

  /// A clarifying question from a `clarify.request` payload or `clarify`
  /// request params. Null when it asks nothing.
  static ClarifyRequest? parseClarify(
    Json payload,
    String sessionId, {
    String? requestId,
  }) {
    final id =
        requestId ??
        HistoryParser.firstText(payload, const ['request_id', 'requestId', 'id']);
    if (id == null || id.isEmpty) return null;
    final questions = <ClarifyQuestion>[];
    for (final entry in payload['questions'].list) {
      final text = HistoryParser.firstText(entry, const ['question', 'prompt', 'text']);
      final qid = HistoryParser.firstText(entry, const ['qid', 'question_id', 'id']);
      if (text == null || qid == null || questions.any((q) => q.id == qid)) {
        continue;
      }
      questions.add(ClarifyQuestion(id: qid, text: text, choices: _choices(entry)));
    }
    if (questions.isEmpty) {
      final text = HistoryParser.firstText(payload, const ['question', 'prompt', 'text']);
      if (text == null) return null;
      questions.add(
        ClarifyQuestion(
          id: 'q0',
          text: text,
          choices: _choices(payload),
          synthetic: true,
        ),
      );
    }
    return ClarifyRequest(requestId: id, sessionId: sessionId, questions: questions);
  }

  /// Offered answers: plain strings, or `{label, value}` objects.
  static List<ClarifyChoice> _choices(Json json) {
    final raw = json['choices'].hasValue ? json['choices'] : json['options'];
    final choices = <ClarifyChoice>[];
    for (final entry in raw.list) {
      final label =
          entry.stringOrNull?.trim() ??
          HistoryParser.firstText(entry, const ['label', 'title', 'text', 'name', 'value']);
      if (label == null || label.isEmpty) continue;
      final value =
          entry.stringOrNull?.trim() ??
          HistoryParser.firstText(entry, const ['value', 'answer', 'id']) ??
          label;
      if (choices.any((c) => c.value == value)) continue;
      choices.add(ClarifyChoice(label: label, value: value));
    }
    return choices;
  }

  /// Text for a value that may be a string or structured JSON.
  static String? _text(Json value) {
    if (value.isNull) return null;
    return value.stringOrNull ?? value.encode();
  }
}
```

```dart
/// Conversations on one dashboard: listing, reading, sending, answering.
///
/// [ChatBackend] is the seam the chat screen depends on, so the screen is
/// tested against a scripted fake. [DashboardChat] is the real one: the live
/// socket for anything live, and REST for stored history — the split Hermes
/// Desktop and Conduit both use, because a long transcript sent over the
/// socket would hold up every event queued behind it.
library;

import 'dart:async';

import '../../core/failure.dart';
import '../../core/result.dart';
import '../rpc/dashboard_session.dart';
import '../rpc/rpc_frame.dart';
import 'chat_event.dart';
import 'chat_models.dart';
import 'history_parser.dart';

/// A conversation Iris just created.
final class NewConversation {
  const NewConversation({required this.runtimeId, required this.storedId});

  /// What live calls and events use.
  final String runtimeId;

  /// What history and the conversation list use.
  final String storedId;
}

/// A stored conversation, attached to the live socket.
final class ResumedConversation {
  const ResumedConversation({
    required this.runtimeId,
    this.running = false,
    this.pending = const [],
  });

  final String runtimeId;

  /// A turn was already in progress — started elsewhere, or before a
  /// reconnect.
  final bool running;

  /// Approvals and questions still waiting for an answer.
  final List<ChatEvent> pending;
}

abstract interface class ChatBackend {
  /// Events and decisions for every live conversation; callers keep the ones
  /// for their own session.
  Stream<ChatEvent> get events;

  Future<Result<List<ConversationSummary>>> conversations();

  /// The newest page of [storedId]'s transcript, oldest first.
  Future<Result<List<TranscriptItem>>> history(String storedId);

  Future<Result<ResumedConversation>> resume(String storedId);

  Future<Result<NewConversation>> create();

  Future<Result<void>> submit(String runtimeId, String text);

  Future<Result<void>> interrupt(String runtimeId);

  Future<Result<void>> answerApproval(ApprovalRequest request, String choice);

  Future<Result<void>> answerClarify(
    ClarifyRequest request,
    ClarifyQuestion question,
    String answer,
  );
}

final class DashboardChat implements ChatBackend {
  DashboardChat(this._session) {
    _eventSubscription = _session.events.listen((event) {
      if (ChatEvent.fromEvent(event) case final parsed?) _events.add(parsed);
    });
    _requestSubscription = _session.serverRequests.listen((request) {
      if (ChatEvent.fromServerRequest(request) case final parsed?) {
        _events.add(parsed);
      }
    });
  }

  /// Rows per history page, as Hermes Desktop asks for.
  static const historyPage = 120;

  /// Long enough for a busy gateway to accept a turn. The reply itself
  /// streams as events, not as this call's result.
  static const submitTimeout = Duration(seconds: 180);

  final DashboardSession _session;
  final _events = StreamController<ChatEvent>.broadcast();
  late final StreamSubscription<RpcEvent> _eventSubscription;
  late final StreamSubscription<RpcServerRequest> _requestSubscription;

  @override
  Stream<ChatEvent> get events => _events.stream;

  @override
  Future<Result<List<ConversationSummary>>> conversations() async =>
      (await _session.call('session.list')).map(HistoryParser.conversations);

  @override
  Future<Result<List<TranscriptItem>>> history(String storedId) async =>
      (await _session.connection.client.get(
        '/api/sessions/${Uri.encodeComponent(storedId)}/messages',
        query: {
          'limit': historyPage,
          'offset': 0,
          'order': 'latest',
          'include_compacted': 'true',
        },
      )).map(HistoryParser.transcript);

  @override
  Future<Result<ResumedConversation>> resume(String storedId) async {
    final result = await _session.call(
      'session.resume',
      params: {
        'session_id': storedId,
        'cols': 96,
        'source': 'desktop',
        'omit_messages': true,
      },
    );
    return result.map((json) {
      final pending = <ChatEvent>[];
      // Decisions asked before Iris attached are re-announced here, under
      // their original server request ids.
      for (final entry in json['open_requests'].list) {
        final method = entry['method'].stringOrNull;
        final id = entry['id'].stringOrNull;
        if (method == null || id == null) continue;
        final request = RpcServerRequest(
          id: id,
          method: method,
          params: entry['params'],
        );
        if (ChatEvent.fromServerRequest(request) case final parsed?) {
          pending.add(parsed);
        }
      }
      return ResumedConversation(
        runtimeId: HistoryParser.firstText(json, const ['session_id']) ?? storedId,
        running: json['running'].boolOrNull ?? json['info']['running'].boolean(),
        pending: pending,
      );
    });
  }

  @override
  Future<Result<NewConversation>> create() async {
    final result = await _session.call(
      'session.create',
      params: const {'cols': 96, 'source': 'desktop'},
    );
    switch (result) {
      case Err(:final failure):
        return Err(failure);
      case Ok(value: final json):
        final runtimeId = HistoryParser.firstText(json, const ['session_id']);
        if (runtimeId == null) {
          return const Err(
            IrisFailure.malformed(
              message: 'The dashboard did not return a session id.',
              endpoint: 'session.create',
            ),
          );
        }
        return Ok(
          NewConversation(
            runtimeId: runtimeId,
            storedId:
                HistoryParser.firstText(json, const ['stored_session_id']) ??
                runtimeId,
          ),
        );
    }
  }

  @override
  Future<Result<void>> submit(String runtimeId, String text) async =>
      (await _session.call(
        'prompt.submit',
        params: {'session_id': runtimeId, 'text': text},
        timeout: submitTimeout,
      )).map((_) {});

  @override
  Future<Result<void>> interrupt(String runtimeId) async => (await _session
      .call('session.interrupt', params: {'session_id': runtimeId})).map((_) {});

  @override
  Future<Result<void>> answerApproval(
    ApprovalRequest request,
    String choice,
  ) async => (await _session.call(
    'approval.respond',
    params: {
      'choice': choice,
      'session_id': request.sessionId,
      if (request.queueId case final queueId?) 'request_id': queueId,
    },
  )).map((_) {});

  @override
  Future<Result<void>> answerClarify(
    ClarifyRequest request,
    ClarifyQuestion question,
    String answer,
  ) async {
    if (!request.isServerRequest) {
      return (await _session.call(
        'clarify.respond',
        params: {
          'request_id': request.requestId,
          'answer': answer,
          if (!question.synthetic) 'question_id': question.id,
        },
      )).map((_) {});
    }
    if (!question.synthetic) {
      // One question of a batch. Each is locked on its own; the last lock
      // resolves the whole request.
      return (await _session.call(
        'clarify.lock',
        params: {
          'request_id': request.requestId,
          'question_id': question.id,
          'answer': answer,
        },
      )).map((_) {});
    }
    // A single question is answered with the response frame itself.
    return _session.replyToServerRequest(request.requestId, {'answer': answer})
        ? const Ok(null)
        : const Err(IrisFailure.offline(message: 'Not connected to the dashboard.'));
  }

  Future<void> dispose() async {
    await _eventSubscription.cancel();
    await _requestSubscription.cancel();
    await _events.close();
  }
}
```

```dart
/// One open conversation's state, and how events change it.
///
/// Pure: `apply` takes an event and returns the next state, so every streaming
/// edge case is a plain unit test rather than a widget test.
library;

import 'package:flutter/foundation.dart';

import '../../core/failure.dart';
import '../../data/chat/chat_event.dart';
import '../../data/chat/chat_models.dart';

enum ChatPhase {
  /// Reading the stored transcript.
  loading,

  /// Showing it; sending works.
  ready,

  /// The transcript could not be read.
  failed,
}

/// What the agent is doing in this conversation right now.
enum TurnPhase { idle, thinking, streaming, working, waiting }

@immutable
final class ChatState {
  const ChatState({
    this.phase = ChatPhase.loading,
    this.items = const [],
    this.turn = TurnPhase.idle,
    this.approvals = const [],
    this.questions = const [],
    this.title,
    this.failure,
  });

  final ChatPhase phase;
  final List<TranscriptItem> items;
  final TurnPhase turn;
  final List<ApprovalRequest> approvals;
  final List<ClarifyRequest> questions;
  final String? title;

  /// Why the transcript could not be read, when [phase] is failed.
  final IrisFailure? failure;

  bool get running => turn != TurnPhase.idle;

  ChatState copyWith({
    ChatPhase? phase,
    List<TranscriptItem>? items,
    TurnPhase? turn,
    List<ApprovalRequest>? approvals,
    List<ClarifyRequest>? questions,
    String? title,
    IrisFailure? failure,
  }) => ChatState(
    phase: phase ?? this.phase,
    items: items ?? this.items,
    turn: turn ?? this.turn,
    approvals: approvals ?? this.approvals,
    questions: questions ?? this.questions,
    title: title ?? this.title,
    failure: failure ?? this.failure,
  );

  /// The state after [event].
  ChatState apply(ChatEvent event) => switch (event) {
    MessageStarted() => copyWith(
      items: _withLive(items),
      turn: TurnPhase.thinking,
    ),
    TextDelta(:final text) => copyWith(
      items: _appendLive(items, text: text),
      turn: TurnPhase.streaming,
    ),
    ReasoningDelta(:final text) => copyWith(
      items: _appendLive(items, reasoning: text),
      turn: turn == TurnPhase.streaming ? turn : TurnPhase.thinking,
    ),
    MessageCompleted(:final content, :final reasoning) => copyWith(
      items: _completed(items, content, reasoning),
      turn: _waitingOr(TurnPhase.idle),
    ),
    ToolStarted(:final toolId, :final name, :final input) => copyWith(
      items: [
        ..._settled(items),
        ToolCall(
          id: toolId ?? 'tool-${items.length}',
          name: name,
          arguments: input,
          status: ToolStatus.running,
        ),
      ],
      turn: TurnPhase.working,
    ),
    final ToolCompleted done => copyWith(
      items: _toolDone(items, done),
      turn: _waitingOr(TurnPhase.thinking),
    ),
    TurnFailed(:final message) => withError(message),
    TurnInterrupted() => copyWith(
      items: [
        ..._settled(items),
        Notice(id: 'notice-${items.length}', text: 'Stopped.'),
      ],
      turn: TurnPhase.idle,
    ),
    BusyChanged(:final busy) =>
      busy
          ? copyWith(turn: turn == TurnPhase.idle ? TurnPhase.thinking : turn)
          : copyWith(items: _settled(items), turn: _waitingOr(TurnPhase.idle)),
    TitleChanged(:final title) => copyWith(title: title),
    ApprovalAsked(:final request) => withApproval(request),
    ClarifyAsked(:final request) => withQuestion(request),
    RequestWithdrawn(:final requestId) => _decided(
      copyWith(
        approvals: [
          for (final approval in approvals)
            if (!approval.matches(requestId)) approval,
        ],
        questions: [
          for (final question in questions)
            if (question.requestId != requestId) question,
        ],
      ),
    ),
  };

  /// The person's message, shown at once.
  ChatState withUserTurn(String text) => copyWith(
    items: [
      ..._settled(items),
      UserTurn(id: 'local-${items.length}', text: text),
    ],
    turn: TurnPhase.thinking,
  );

  /// A failure, shown inline; the turn ends unless a decision is waiting.
  ChatState withError(String message) => copyWith(
    items: [
      ..._settled(items),
      Notice(id: 'notice-${items.length}', text: message, isError: true),
    ],
    turn: _waitingOr(TurnPhase.idle),
  );

  ChatState withApproval(ApprovalRequest request) => copyWith(
    approvals: [
      for (final approval in approvals)
        if (!_sameApproval(approval, request)) approval,
      request,
    ],
    turn: TurnPhase.waiting,
  );

  ChatState withoutApproval(ApprovalRequest request) => _decided(
    copyWith(
      approvals: [
        for (final approval in approvals)
          if (!_sameApproval(approval, request)) approval,
      ],
    ),
  );

  ChatState withQuestion(ClarifyRequest request) => copyWith(
    questions: [
      for (final question in questions)
        if (question.requestId != request.requestId) question,
      request,
    ],
    turn: TurnPhase.waiting,
  );

  /// [question] of [request] answered; the request goes once none remain.
  ChatState withoutQuestion(ClarifyRequest request, ClarifyQuestion question) {
    final remaining = request.without(question.id);
    return _decided(
      copyWith(
        questions: [
          for (final pending in questions)
            if (pending.requestId != request.requestId)
              pending
            else if (remaining.questions.isNotEmpty)
              remaining,
        ],
      ),
    );
  }

  TurnPhase _waitingOr(TurnPhase phase) =>
      approvals.isNotEmpty || questions.isNotEmpty ? TurnPhase.waiting : phase;

  /// After a decision: back to thinking once nothing is waiting.
  static ChatState _decided(ChatState next) =>
      next.turn == TurnPhase.waiting &&
          next.approvals.isEmpty &&
          next.questions.isEmpty
      ? next.copyWith(turn: TurnPhase.thinking)
      : next;

  static bool _sameApproval(ApprovalRequest a, ApprovalRequest b) =>
      identical(a, b) ||
      (a.serverRequestId != null && a.serverRequestId == b.serverRequestId) ||
      (a.queueId != null && a.queueId == b.queueId);

  /// [items] with a live assistant turn at the end, creating one if needed.
  static List<TranscriptItem> _withLive(List<TranscriptItem> items) {
    final last = items.isEmpty ? null : items.last;
    if (last is AssistantTurn && last.streaming) return items;
    return [
      ...items,
      AssistantTurn(id: 'live-${items.length}', text: '', streaming: true),
    ];
  }

  static List<TranscriptItem> _appendLive(
    List<TranscriptItem> items, {
    String text = '',
    String reasoning = '',
  }) {
    final withLive = _withLive(items);
    final live = withLive.last;
    if (live is! AssistantTurn) return withLive;
    return [
      ...withLive.sublist(0, withLive.length - 1),
      live.copyWith(
        text: live.text + text,
        reasoning: live.reasoning + reasoning,
      ),
    ];
  }

  /// [items] with the live assistant turn finished: kept if it says
  /// anything, dropped if it never did.
  static List<TranscriptItem> _settled(List<TranscriptItem> items) {
    final last = items.isEmpty ? null : items.last;
    if (last is! AssistantTurn || !last.streaming) return items;
    final rest = items.sublist(0, items.length - 1);
    return last.isEmpty ? rest : [...rest, last.copyWith(streaming: false)];
  }

  static List<TranscriptItem> _completed(
    List<TranscriptItem> items,
    String? content,
    String? reasoning,
  ) {
    final last = items.isEmpty ? null : items.last;
    if (last is AssistantTurn && last.streaming) {
      final rest = items.sublist(0, items.length - 1);
      // The deltas win. The complete event's text fills in only when no text
      // arrived in this turn at all, because it may repeat what was said
      // before a tool call.
      final finished = last.copyWith(
        text: last.text.trim().isEmpty && _has(content) && !_turnHasText(rest)
            ? content
            : null,
        reasoning: last.reasoning.trim().isEmpty && _has(reasoning)
            ? reasoning
            : null,
        streaming: false,
      );
      return finished.isEmpty ? rest : [...rest, finished];
    }
    if (!_has(content) || _turnHasText(items)) return items;
    return [
      ...items,
      AssistantTurn(
        id: 'live-${items.length}',
        text: content!,
        reasoning: reasoning ?? '',
      ),
    ];
  }

  static bool _has(String? text) => text != null && text.trim().isNotEmpty;

  /// Whether the agent already said something since the person last spoke.
  static bool _turnHasText(List<TranscriptItem> items) {
    for (final item in items.reversed) {
      if (item is UserTurn) return false;
      if (item is AssistantTurn && item.text.trim().isNotEmpty) return true;
    }
    return false;
  }

  static List<TranscriptItem> _toolDone(
    List<TranscriptItem> items,
    ToolCompleted done,
  ) {
    final status = done.failed ? ToolStatus.failed : ToolStatus.done;
    final toolId = done.toolId;
    var at = toolId == null
        ? null
        : _lastToolIndex(items, (call) => call.id == toolId);
    at ??= _lastToolIndex(
      items,
      (call) => call.status == ToolStatus.running && call.name == done.name,
    );
    if (at != null) {
      final call = items[at];
      if (call is ToolCall) {
        return [
          ...items.sublist(0, at),
          call.copyWith(output: done.output, status: status),
          ...items.sublist(at + 1),
        ];
      }
    }
    return [
      ..._settled(items),
      ToolCall(
        id: toolId ?? 'tool-${items.length}',
        name: done.name,
        output: done.output,
        status: status,
      ),
    ];
  }

  static int? _lastToolIndex(
    List<TranscriptItem> items,
    bool Function(ToolCall call) test,
  ) {
    for (var i = items.length - 1; i >= 0; i--) {
      final item = items[i];
      if (item is ToolCall && test(item)) return i;
    }
    return null;
  }
}
```

```dart
/// One open conversation: loads it, follows its live events, sends, stops and
/// answers.
///
/// A [ValueNotifier] rather than a provider: a conversation lives exactly as
/// long as its screen, and the screen owns it.
library;

import 'dart:async';

import 'package:flutter/foundation.dart';

import '../../core/failure.dart';
import '../../core/result.dart';
import '../../data/chat/chat_backend.dart';
import '../../data/chat/chat_event.dart';
import '../../data/chat/chat_models.dart';
import 'chat_state.dart';

final class ChatController extends ValueNotifier<ChatState> {
  ChatController(this._backend, {String? conversationId, String? title})
    : _storedId = conversationId,
      super(
        ChatState(
          phase: conversationId == null ? ChatPhase.ready : ChatPhase.loading,
          title: title,
        ),
      );

  final ChatBackend _backend;
  String? _storedId;
  String? _runtimeId;
  StreamSubscription<ChatEvent>? _subscription;
  bool _disposed = false;

  /// The stored id: given when opened, or set by a new chat's first send.
  String? get conversationId => _storedId;

  /// Starts following events, then reads the transcript and attaches to it.
  Future<void> open() async {
    _subscription ??= _backend.events.listen(_onEvent);
    final storedId = _storedId;
    if (storedId == null) return;
    _update(ChatState(title: value.title));
    switch (await _backend.history(storedId)) {
      case Err(:final failure):
        _update(value.copyWith(phase: ChatPhase.failed, failure: failure));
        return;
      case Ok(value: final items):
        _update(value.copyWith(phase: ChatPhase.ready, items: items));
    }
    if (_disposed) return;
    switch (await _backend.resume(storedId)) {
      case Err(:final failure):
        // Readable but not live: the history stays, and the transcript says
        // why sending may not work.
        _update(value.withError(describe(failure)));
      case Ok(value: final resumed):
        _runtimeId = resumed.runtimeId;
        var next = value.copyWith(
          turn: resumed.running ? TurnPhase.thinking : null,
        );
        for (final event in resumed.pending) {
          next = next.apply(event);
        }
        _update(next);
    }
  }

  /// Sends [text], creating the conversation first if this is a new chat.
  Future<void> send(String text) async {
    final trimmed = text.trim();
    if (trimmed.isEmpty || value.running) return;
    _update(value.withUserTurn(trimmed));
    final runtimeId = _runtimeId ?? await _create();
    if (runtimeId == null) return;
    final sent = await _backend.submit(runtimeId, trimmed);
    if (sent case Err(:final failure)) {
      _update(value.withError(describe(failure)));
    }
  }

  /// Stops the running turn.
  Future<void> stop() async {
    final runtimeId = _runtimeId;
    if (runtimeId == null || !value.running) return;
    final result = await _backend.interrupt(runtimeId);
    if (result case Err(:final failure)) {
      _update(value.withError(describe(failure)));
    }
  }

  /// Answers [request] with [choice]. The card goes at once and comes back if
  /// the answer could not be sent, so the agent is never left waiting on a
  /// card nobody can see.
  Future<void> approve(ApprovalRequest request, String choice) async {
    _update(value.withoutApproval(request));
    final result = await _backend.answerApproval(request, choice);
    if (result case Err(:final failure)) {
      _update(
        value
            .withApproval(request)
            .withError('Could not send the answer: ${describe(failure)}'),
      );
    }
  }

  /// Answers one [question] of [request].
  Future<void> answer(
    ClarifyRequest request,
    ClarifyQuestion question,
    String answer,
  ) async {
    final text = answer.trim();
    if (text.isEmpty) return;
    _update(value.withoutQuestion(request, question));
    final result = await _backend.answerClarify(request, question, text);
    if (result case Err(:final failure)) {
      _update(
        value
            .withQuestion(request)
            .withError('Could not send the answer: ${describe(failure)}'),
      );
    }
  }

  /// What to say about [failure] in the transcript.
  static String describe(IrisFailure failure) => switch (failure.kind) {
    FailureKind.offline =>
      'Not connected to your agent. Iris reconnects on its own; try again in '
          'a moment.',
    FailureKind.timeout => 'Your agent did not answer in time.',
    _ => failure.message ?? 'Something went wrong (${failure.kind.name}).',
  };

  /// Creates the conversation behind a new chat. Null if that failed, after
  /// saying why in the transcript.
  Future<String?> _create() async {
    switch (await _backend.create()) {
      case Err(:final failure):
        _update(value.withError(describe(failure)));
        return null;
      case Ok(value: final created):
        _storedId = created.storedId;
        return _runtimeId = created.runtimeId;
    }
  }

  void _onEvent(ChatEvent event) {
    final id = event.sessionId;
    if (id.isEmpty || (id != _runtimeId && id != _storedId)) return;
    _update(value.apply(event));
  }

  void _update(ChatState next) {
    if (!_disposed) value = next;
  }

  @override
  void dispose() {
    _disposed = true;
    unawaited(_subscription?.cancel());
    super.dispose();
  }
}
```

```dart
const _months = [
  'Jan',
  'Feb',
  'Mar',
  'Apr',
  'May',
  'Jun',
  'Jul',
  'Aug',
  'Sep',
  'Oct',

/// How long before [now] [time] was, in the fewest words that still order a
/// list. A time ahead of [now] — clock skew between phone and server — reads
/// as "just now".
String relativeTime(DateTime time, DateTime now) {
  final age = now.difference(time);
  if (age.inMinutes < 1) return 'just now';
  if (age.inHours < 1) return '${age.inMinutes}m ago';
  if (age.inDays < 1) return '${age.inHours}h ago';
  if (age.inDays < 7) return '${age.inDays}d ago';
  final date = '${time.day} ${_months[time.month - 1]}';
  return time.year == now.year ? date : '$date ${time.year}';
}
```

```dart
AgentState agentStateFor(TurnPhase turn) => switch (turn) {
  TurnPhase.idle => AgentState.idle,
  TurnPhase.thinking => AgentState.thinking,
  TurnPhase.streaming => AgentState.streaming,
  TurnPhase.working => AgentState.working,
  TurnPhase.waiting => AgentState.waiting,
};

class ChatScreen extends StatefulWidget {
  const ChatScreen({
    required this.backend,
    this.conversationId,
    this.title,
    super.key,
  });

  final ChatBackend backend;

  /// The stored conversation to open; null starts a new one.
  final String? conversationId;
  final String? title;

  @override
  State<ChatScreen> createState() => _ChatScreenState();
}

class _ChatScreenState extends State<ChatScreen> {
  late final ChatController _chat = ChatController(
    widget.backend,
    conversationId: widget.conversationId,
    title: widget.title,
  );
  final _text = TextEditingController();

  @override
  void initState() {
    super.initState();
    unawaited(_chat.open());
  }

  @override
  void dispose() {
    _chat.dispose();
    _text.dispose();
    super.dispose();
  }

  void _send() {
    final text = _text.text;
    if (text.trim().isEmpty) return;
    _text.clear();
    unawaited(_chat.send(text));
  }

  @override
  Widget build(BuildContext context) => ValueListenableBuilder<ChatState>(
    valueListenable: _chat,
    builder: (context, state, _) => IrisScaffold(
      header: _ChatHeader(
        title: state.title ?? 'New conversation',
        turn: state.turn,
      ),
      body: _body(context, state),
      footer: Column(
        mainAxisSize: MainAxisSize.min,
        crossAxisAlignment: CrossAxisAlignment.stretch,
        children: [
          if (state.approvals.isNotEmpty)
            _Decision(
              child: ApprovalCard(
                request: state.approvals.first,
                onChoose: (choice) =>
                    unawaited(_chat.approve(state.approvals.first, choice)),
              ),
            )
          else if (state.questions.isNotEmpty)
            _Decision(
              child: ClarifyCard(
                key: ValueKey(
                  '${state.questions.first.requestId}/'
                  '${state.questions.first.questions.length}',
                ),
                request: state.questions.first,
                onAnswer: (question, answer) => unawaited(
                  _chat.answer(state.questions.first, question, answer),
                ),
              ),
            ),
          Composer(
            controller: _text,
            running: state.running,
            enabled: state.phase == ChatPhase.ready,
            onSend: _send,
            onStop: () => unawaited(_chat.stop()),
          ),
        ],
      ),
    ),
  );

  Widget _body(BuildContext context, ChatState state) {
    switch (state.phase) {
      case ChatPhase.loading:
        return const Center(
          child: Aperture(state: AgentState.thinking, size: 32),
        );
      case ChatPhase.failed:
        return IrisEmptyState(
          title: 'Could not open this conversation',
          message: state.failure?.message ?? 'The dashboard did not return it.',
          action: IrisButton(
            label: 'Try again',
            tone: IrisButtonTone.primary,
            onPressed: () => unawaited(_chat.open()),
          ),
        );
      case ChatPhase.ready:
        final items = state.items;
        if (items.isEmpty) {
          return const IrisEmptyState(
            title: 'New conversation',
            message: 'Ask your agent anything.',
          );
        }
        // Reversed, so the newest entry sits at the bottom and new output
        // appears where the eye already is.
        return ListView.separated(
          reverse: true,
          padding: EdgeInsets.symmetric(
            horizontal: context.window.gutter,
            vertical: IrisSpace.lg,
          ),
          itemCount: items.length,
          separatorBuilder: (_, _) => const SizedBox(height: IrisSpace.md),
          itemBuilder: (context, index) {
            final item = items[items.length - 1 - index];
            return ReadableColumn(
              child: TranscriptEntry(item, key: ValueKey(item.id)),
            );
          },
        );
    }
```

```dart
class _ConversationList extends StatelessWidget {
  const _ConversationList({
    required this.conversations,
    required this.onOpen,
    required this.onRetry,
  });

  final AsyncValue<List<ConversationSummary>?> conversations;
  final ValueChanged<ConversationSummary>? onOpen;
  final VoidCallback onRetry;

  static String? _subtitle(ConversationSummary conversation, DateTime now) {
    final parts = [
      if (conversation.startedAt case final at?) relativeTime(at, now),
      if (conversation.source case final source? when source != 'desktop')
        source,
      if (conversation.messageCount > 0)
        '${conversation.messageCount} messages',
    ];
    return parts.isEmpty ? null : parts.join(' · ');
  }

  @override
  Widget build(BuildContext context) {
    final gutter = context.window.gutter;
    final list = conversations.value;
    if (list == null) {
      if (conversations.error case final error?) {
        return IrisEmptyState(
          title: 'Could not load conversations',
          message: error is IrisFailure
              ? error.message ?? error.kind.name
              : '$error',
          action: IrisButton(label: 'Try again', onPressed: onRetry),
        );

      // Loading, or waiting for the link: placeholders where rows will be.
      return ListView(
        padding: EdgeInsets.symmetric(
          horizontal: gutter,
          vertical: IrisSpace.md,
        ),
        children: [
          for (var i = 0; i < 6; i++) ...[
            const IrisSkeleton(width: 220, height: 16),
            const SizedBox(height: IrisSpace.xs),
            const IrisSkeleton(width: 120, height: 12),
            const SizedBox(height: IrisSpace.lg),
          ],
        ],
      );
    }
    if (list.isEmpty) {
      return const IrisEmptyState(
        title: 'No conversations yet',
        message: 'Start one below. It will show here and in every other '
            'client of this agent.',
      );
    }
    final now = DateTime.now();
    final open = onOpen;
    return ListView.builder(
      padding: EdgeInsets.symmetric(
        horizontal: gutter - IrisSpace.md,
        vertical: IrisSpace.sm,
      ),
      itemCount: list.length,
      itemBuilder: (context, index) {
        final conversation = list[index];
        return IrisListRow(
          key: ValueKey(conversation.id),
          title: conversation.title,
          subtitle: _subtitle(conversation, now),
          onTap: open == null ? null : () => open(conversation),
        );
      },
    );
  }
```

```dart
///
/// It creates a conversation on the server, so it runs only when asked for:
///   flutter test --tags live_write --run-skipped test/live/chat_write_live_test.dart
/// Prints event kinds only, never content.
@Tags(['live_write'])
library;

import 'dart:async';
import 'dart:io';

import 'package:flutter_test/flutter_test.dart';
import 'package:iris/core/json.dart';
import 'package:iris/data/chat/chat_backend.dart';
import 'package:iris/data/chat/chat_event.dart';
import 'package:iris/data/net/credentials.dart';
import 'package:iris/data/net/server_config.dart';
import 'package:iris/data/net/server_connection.dart';
import 'package:iris/data/rpc/dashboard_session.dart';

void main() {
  test(
    'a prompt streams a reply',
    () async {
      final json = Json.decode(
        File(
          '${Platform.environment['USERPROFILE'] ?? Platform.environment['HOME']}'
          '/.iris-live.json',
        ).readAsStringSync(),
      );
      final connection = ServerConnection.create(
        ServerConfig(
          id: 'live',
          baseUrl: ServerConfig.normaliseBaseUrl(json['base_url'].string()),
          label: 'live',
        ),
        secrets: ServerSecrets(
          username: json['username'].stringOrNull,
          password: json['password'].stringOrNull,
          accessClientId: json['cf_client_id'].stringOrNull,
          accessClientSecret: json['cf_client_secret'].stringOrNull,
        ),
      );
      final session = DashboardSession(http: connection);
      final chat = DashboardChat(session);
      addTearDown(() async {
        await chat.dispose();
        await session.dispose();
        connection.close();
      });
      await session.start();
      expect(session.state.phase, LinkPhase.live);

      final created = (await chat.create()).valueOrNull!;
      final kinds = <String>{};
      final reply = StringBuffer();
      final done = Completer<void>();
      final subscription = chat.events
          .where((event) => event.sessionId == created.runtimeId)
          .listen((event) {
            kinds.add(event.runtimeType.toString());
            switch (event) {
              case TextDelta(:final text):
                reply.write(text);
              case MessageCompleted(:final content):
                if (reply.isEmpty) reply.write(content ?? '');
                if (!done.isCompleted) done.complete();
              case BusyChanged(busy: false) when reply.isNotEmpty:
                if (!done.isCompleted) done.complete();
              case TurnFailed(:final message):
                if (!done.isCompleted) done.completeError(message);
              default:
                break;
            }
          });
      addTearDown(subscription.cancel);

      final sent = await chat.submit(
        created.runtimeId,
        'Reply with exactly the word: pong',
      );
      expect(sent.isOk, isTrue, reason: '${sent.failureOrNull}');
      await done.future.timeout(const Duration(seconds: 90));
      stdout.writeln('event kinds: $kinds');
      expect(reply.toString().toLowerCase(), contains('pong'));
    },
    timeout: const Timeout(Duration(seconds: 120)),
  );
}
```
