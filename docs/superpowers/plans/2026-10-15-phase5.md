# Phase 5 — Maths, Richer Markdown, Media and Input Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans (recommended here) or
> superpowers:subagent-driven-development to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax.

**Goal:** Render TeX maths and GitHub-style Markdown in replies, show Markdown images on tap, detect unlabelled code
languages, and let the person send photos, files and dictated speech.

**Architecture:** New Markdown syntax goes into `package:markdown` as syntaxes (`markdown_syntax.dart`, plain Dart and
unit-testable), and `IrisMarkdown`'s renderer draws the new tags from design tokens. Maths is laid out by
`flutter_math_fork` in its own `IrisMath` widget. Attachments and transcription are two new `ChatBackend` methods that
follow Conduit's wire calls. The composer gets a picker button, attachment chips and a mic, with the picker and
recorder injected so widget tests use fakes.

**Tech Stack:** Flutter 3.41.6, `markdown` 7.3.1 (already present), `re_highlight` 0.0.3 (already present), new
dependencies `flutter_math_fork` ^0.7.4, `file_picker` ^13.1.0 and `record` ^6.2.1.

**Spec:** `docs/superpowers/specs/2026-10-15-phase5-design.md`

## Token budget — how this plan keeps the build cheap

- **Run it natively in one session** (superpowers:executing-plans), not subagent-driven. Eleven tasks share a handful of
  files (`markdown.dart`, `composer.dart`, `chat_backend.dart`). A fresh agent per task would re-read them every time.
  The user's policy is no subagents anyway.
- **A Sonnet session is enough.** The plan carries the design. Keep Opus for the single end-of-branch review.
- **Read only what a task names.** Every task lists its files and anchors. Don't re-explore the codebase.
- **Run only the task's test file after each task.** Run `flutter analyze` and the full suite once, in Task 10.
- **No new goldens.** The device pass's screenshots cover the visual check. Golden regeneration loops are the most
  expensive kind of iteration in this repo.
- **One device pass, at the end,** using the release APK (the debug APK is 226 MB, and the emulator disk was 92% full
  last time).

## Global Constraints

- Iris talks only to the user's own server. Nothing is fetched from a third party unless the person taps for it.
- No CDN, no WebView. Fonts and TeX fonts are bundled.
- Commits are under the user's name only. **No `Co-Authored-By` trailer and no Claude attribution** (user rule; this
  overrides the harness default).
- Prose in code comments, copy and docs: British spelling, Iris's plain voice, no raw error codes in a primary line.
- Limits: 5 attachments per message, 20 MB per file, 2 minutes per recording.
- Half-written Markdown or TeX (normal while streaming) never throws. It renders as text.
- The demo backend (`lib/demo/`) must keep working offline for every new feature.

```dart
// lib/design/components/markdown_syntax.dart
/// The Markdown Iris reads: GitHub's web flavour (tables, task lists,
/// footnotes, alerts, emoji) plus the few HTML tags agents use for
/// typography. Plain Dart, so it is tested without widgets.
library;

import 'package:markdown/markdown.dart' as md;

/// Inline syntaxes tried before GitHub's own, in order.
final List<md.InlineSyntax> irisInlineSyntaxes = [TypographyHtmlSyntax()];

/// Block syntaxes tried before GitHub's own, in order.
final List<md.BlockSyntax> irisBlockSyntaxes = [];

/// The parser for a reply. HTML is left unescaped: the renderer draws text,
/// never HTML, so there is nothing to inject into.
md.Document irisDocument() => md.Document(
  extensionSet: md.ExtensionSet.gitHubWeb,
  blockSyntaxes: irisBlockSyntaxes,
  inlineSyntaxes: irisInlineSyntaxes,
  encodeHtml: false,
);

/// `<sub>`, `<sup>`, `<kbd>` and `<mark>` around plain text, and `<br>`.
/// Anything else that looks like HTML stays as typed.
class TypographyHtmlSyntax extends md.InlineSyntax {
  TypographyHtmlSyntax()
    : super(
        r'<(sub|sup|kbd|mark)>([^<]*)</\1>|<br\s*/?>',
        startCharacter: 0x3C, // <
        caseSensitive: false,
      );

  @override
  bool onMatch(md.InlineParser parser, Match match) {
    final tag = match[1];
    parser.addNode(
      tag == null
          ? md.Element.empty('br')
          : md.Element.text(tag.toLowerCase(), match[2]!),
    );
    return true;
  }
}
```

```dart
        ...const <md.Node>[]
      else if (node is md.Element && node.tag == 'p')
```

```dart
/// Elements the renderer draws as maths. Their only text is the TeX source.
const mathInlineTag = 'math-inline';
const mathDisplayTag = 'math-display';

/// Inline maths: `\(…\)`, `\[…\]` and `$$…$$` within a line, and `$…$` by
/// Pandoc's rule. The opening `$` is not followed by a space, the closing
/// one is not preceded by one and not followed by a digit, so prices stay
/// text.
class MathInlineSyntax extends md.InlineSyntax {
  MathInlineSyntax()
    : super(
        r'\$\$([^$]+?)\$\$'
        r'|\\\((.+?)\\\)'
        r'|\\\[(.+?)\\\]'
        r'|\$(?![\s$])((?:\\\$|[^$\n])+?)(?<![\s\\])\$(?!\d)',
      );

  @override
  bool onMatch(md.InlineParser parser, Match match) {
    final display = match[1] ?? match[3];
    final tex = (display ?? match[2] ?? match[4]!).trim();
    parser.addNode(
      md.Element.text(display == null ? mathInlineTag : mathDisplayTag, tex),
    );
    return true;
  }
}

/// A display block: a line opening with `$$` or `\[`, through the line that
/// closes it. A block whose close hasn't arrived (normal while a reply
/// streams) isn't claimed, so it shows as text instead of swallowing the
/// rest of the reply.
class MathBlockSyntax extends md.BlockSyntax {
  const MathBlockSyntax();

  static final _open = RegExp(r'^ {0,3}(\$\$|\\\[)(.*)$');

  /// How far ahead a close is looked for.
  static const _maxLines = 200;

  @override
  RegExp get pattern => _open;

  @override
  bool canParse(md.BlockParser parser) => _span(parser) != null;

  @override
  md.Node? parse(md.BlockParser parser) {
    final (tex, lines) = _span(parser)!;
    for (var i = 0; i < lines; i++) {
      parser.advance();
    }
    return md.Element.text(mathDisplayTag, tex);
  }

  /// The TeX and the number of lines it covers, or null when unclosed.
  static (String, int)? _span(md.BlockParser parser) {
    final match = _open.firstMatch(parser.current.content);
    if (match == null) return null;
    final close = match[1] == r'$$' ? r'$$' : r'\]';
    final first = match[2]!.trimRight();
    if (first.endsWith(close)) {
      final tex = first.substring(0, first.length - close.length).trim();
      return tex.isEmpty ? null : (tex, 1);
    }
    final body = <String>[first];
    for (var ahead = 1; ahead <= _maxLines; ahead++) {
      final line = parser.peek(ahead);
      if (line == null) return null;
      final text = line.content.trimRight();
      if (text.endsWith(close)) {
        body.add(text.substring(0, text.length - close.length));
        final tex = body.join('\n').trim();
        return tex.isEmpty ? null : (tex, ahead + 1);
      }
      body.add(text);
    }
    return null;
  }
}
```

```dart
/// TeX, typeset. `flutter_math_fork` lays it out in Dart with bundled KaTeX
/// fonts: no WebView and no CDN. TeX that doesn't parse, often half-written
/// while a reply streams, shows as its source in code type.

import 'package:flutter/material.dart';
import 'package:flutter_math_fork/flutter_math.dart';

import '../theme/iris_theme.dart';

class IrisMath extends StatelessWidget {
  const IrisMath(this.tex, {required this.display, required this.style, super.key});

  final String tex;

  /// A block of its own: larger, centred and scrollable sideways.
  final bool display;

  /// The text around it, whose size and colour the maths takes.
  final TextStyle style;

  @override
  Widget build(BuildContext context) {
    final math = Math.tex(
      tex,
      mathStyle: display ? MathStyle.display : MathStyle.text,
      textStyle: style,
      onErrorFallback: (_) => Text(
        display ? tex : '\$$tex\$',
        style: context.type.code.copyWith(
          fontSize: (style.fontSize ?? 16) * 0.9,
          color: context.palette.inkMuted,
        ),
```

```dart
/// [tex] rewritten for the parser: chemistry expanded, optional derivative
/// orders made plain arguments, and AMS environments mapped to the ones
/// it has.
String prepareTex(String tex) => _replaceCe(tex)
    .replaceAllMapped(
      RegExp(r'\\(dv|pdv)\[([^\]]*)\]'),
      (m) => '\\iris${m[1]}n{${m[2]}}',
    )
    .replaceAllMapped(
      RegExp(r'\\(begin|end)\{(align|flalign|eqnarray|split)\*?\}'),
      (m) => '\\${m[1]}{aligned}',
    )
    .replaceAllMapped(
      RegExp(r'\\(begin|end)\{alignat\*?\}'),
      (m) => '\\${m[1]}{alignedat}',
    )
    .replaceAll(RegExp(r'\\begin\{(gather|multline)\*?\}'), r'\begin{array}{c}')
    .replaceAll(RegExp(r'\\end\{(gather|multline)\*?\}'), r'\end{array}')
    .replaceAll(RegExp(r'\\(begin|end)\{(equation|displaymath)\*?\}'), '');

/// Every `\ce{…}` replaced, braces matched. An unclosed one is left alone,
/// so the parser fails and the source shows.
String _replaceCe(String tex) {
  final out = StringBuffer();
  var i = 0;
  while (true) {
    final start = tex.indexOf(r'\ce{', i);
    if (start < 0) break;
    var depth = 0;
    var end = -1;
    for (var j = start + 3; j < tex.length; j++) {
      if (tex[j] == '{') depth++;
      if (tex[j] == '}' && --depth == 0) {
        end = j;
        break;
      }
    }
    if (end < 0) break;
    out
      ..write(tex.substring(i, start))
      ..write('{${_mhchem(tex.substring(start + 4, end))}}');
    i = end + 1;
  }
  return (out..write(tex.substring(i))).toString();
}

/// mhchem's common cases: formulas, coefficients, charges, states and
/// arrows. Anything stranger draws as upright text, which still reads.
String _mhchem(String source) {
  const arrows = {
    '<=>': r'\rightleftharpoons',
    '<->': r'\leftrightarrow',
    '->': r'\rightarrow',
    '<-': r'\leftarrow',
  };
  return [
    for (final token in source.trim().split(RegExp(r'\s+')))
      arrows[token] ?? (token == '+' ? '+' : _species(token)),
  ].join(' ');
}

String _species(String token) {
  final parts = RegExp(r'^(\d+(?:/\d+)?)?(.*)$').firstMatch(token)!;
  final coefficient = parts[1] ?? '';
  var body = parts[2]!;
  var state = '';
  final s = RegExp(r'\((s|l|g|aq)\)$').firstMatch(body);
  if (s != null) {
    state = '\\,(\\mathrm{${s[1]}})';
    body = body.substring(0, s.start);
  }
  var charge = '';
  final c =
      RegExp(r'\^\{?(\d*[+-])\}?$').firstMatch(body) ??
      RegExp(r'(?<=[A-Za-z\d)\]])(\d*[+-])$').firstMatch(body);
  if (c != null && c.start > 0) {
    charge = '^{${c[1]}}';
    body = body.substring(0, c.start);
  }
  final formula = body.replaceAllMapped(
    RegExp(r'([A-Za-z)\]])(\d+)'),
    (x) => '${x[1]}_{${x[2]}}',
  );
  return '$coefficient\\mathrm{$formula}$charge$state';
}
```

```dart
// lib/data/chat/attachment.dart
/// A file sent with a prompt, and how the prompt names it. Hermes stages a
/// file in the session and answers with an `@file:` reference; the prompt
/// carries those references ahead of the typed text, the way Hermes Desktop
/// and Conduit send them.
library;

import 'dart:convert';
import 'dart:typed_data';

import 'package:path/path.dart' as p;

final class Attachment {
  const Attachment({required this.name, required this.bytes});

  final String name;
  final Uint8List bytes;

  /// Larger files are refused before upload: base64 over the socket grows
  /// them by a third.
  static const maxBytes = 20 * 1024 * 1024;
  static const maxPerMessage = 5;

  static const _types = {
    '.png': 'image/png',
    '.jpg': 'image/jpeg',
    '.jpeg': 'image/jpeg',
    '.gif': 'image/gif',
    '.webp': 'image/webp',
    '.heic': 'image/heic',
    '.pdf': 'application/pdf',
    '.txt': 'text/plain',
    '.md': 'text/markdown',
    '.csv': 'text/csv',
    '.json': 'application/json',
  };

  String get mimeType =>
      _types[p.extension(name).toLowerCase()] ?? 'application/octet-stream';

  bool get isImage => mimeType.startsWith('image/');

  String get dataUrl => 'data:$mimeType;base64,${base64Encode(bytes)}';
}

/// The prompt Hermes receives: each reference on its own line, a blank
/// line, then the typed text.
String promptWithReferences(String text, List<String> references) {
  if (references.isEmpty) return text;
  final head = references.join('\n');
  return text.trim().isEmpty ? head : '$head\n\n$text';
}

final _reference = RegExp(r'''^@file:(?:"([^"]*)"|'([^']*)'|`([^`]*)`|(\S+))\s*$''');

/// A stored prompt's leading `@file:` lines as file names, and the rest.
(List<String>, String) splitReferences(String prompt) {
  final lines = prompt.split('\n');
  final names = <String>[];
  var i = 0;
  for (; i < lines.length; i++) {
    final match = _reference.firstMatch(lines[i].trim());
    if (match == null) break;
    final path = match[1] ?? match[2] ?? match[3] ?? match[4]!;
    names.add(p.posix.basename(path));
  }
  if (names.isEmpty) return (const [], prompt);
  return (names, lines.skip(i).join('\n').trim());
}

/// A path as Hermes reads it back whole: quoted when it holds whitespace,
/// brackets or quotes (its `format_reference_value`).
String formatReferenceValue(String value) {
  if (!RegExp(r'''[\s()\[\]{}"'`]''').hasMatch(value)) return value;
  for (final quote in const ['`', '"', "'"]) {
    if (!value.contains(quote)) return '$quote$value$quote';
  }
  return value;
}
```

```dart
  /// Long enough to send 20 MB as base64 over a slow uplink.
  static const attachTimeout = Duration(seconds: 120);

  @override
  Future<Result<String?>> attach(String runtimeId, Attachment file) async {
    if (file.isImage) {
      final sent = await _session.call(
        'image.attach_bytes',
        params: {
          'session_id': runtimeId,
          'content_base64': base64Encode(file.bytes),
          'filename': file.name,
        },
        timeout: attachTimeout,
      );
      switch (sent) {
        case Ok():
          return const Ok(null);
        case Err(:final failure) when !_refusedAsImage(failure):
          return Err(failure);
        case Err():
        // Hermes won't take it as an image (a format it doesn't list, or past
        // its image size cap). It still goes up, as a file.
      }
    }
    final staged = await _session.call(
      'file.attach',
      params: {
        'session_id': runtimeId,
        'data_url': file.dataUrl,
        'name': file.name,
        'path': '',
      },
      timeout: attachTimeout,
    );
    return staged.map(_fileReference);
  }

  static bool _refusedAsImage(IrisFailure failure) =>
      failure.cause case RpcError(code: 4016 || 4018);

  /// The reply's `ref_text`, or one built from the staged path.
  static String? _fileReference(Json result) {
    final text = result['ref_text'].stringOrNull?.trim();
    if (text != null && text.startsWith('@file:') && text.length > 6) {
      return text;
    }
    final path = [result['ref_path'].stringOrNull, result['path'].stringOrNull]
        .map((s) => s?.trim())
        .firstWhere((s) => s != null && s.isNotEmpty, orElse: () => null);
    return path == null ? null : '@file:${formatReferenceValue(path)}';
  }
```

```dart
  static const transcribeTimeout = Duration(seconds: 90);

  @override
  Future<Result<String>> transcribe(Uint8List wav) async {
    const route = '/api/audio/transcribe';
    final sent = await _session.connection.client.post(
      route,
      body: {
        'data_url': 'data:audio/wav;base64,${base64Encode(wav)}',
        'mime_type': 'audio/wav',
      },
      query: _scoped({}),
      receiveTimeout: transcribeTimeout,
    );
    switch (sent) {
      case Err(:final failure):
        return Err(failure);
      case Ok(:final value):
        final error = value['error'].stringOrNull?.trim();
        if (error != null && error.isNotEmpty) {
          return Err(IrisFailure(FailureKind.server, message: error, endpoint: route));
        }
        final words = value['transcript'].stringOrNull ?? value['text'].stringOrNull;
        if (words == null) {
          return Err(const IrisFailure(
            FailureKind.malformed,
            message: "Hermes didn't send back what you said.",
            endpoint: route,
          ));
        }
        return Ok(words.trim());
    }
  }
```

```dart
// lib/features/chat/voice_recorder.dart
/// Recording a short clip for dictation: 16 kHz mono WAV, what Hermes'
/// speech-to-text expects.
library;

import 'dart:io';
import 'dart:typed_data';

import 'package:path/path.dart' as p;
import 'package:path_provider/path_provider.dart';
import 'package:record/record.dart';

abstract interface class VoiceRecorder {
  /// Starts recording. False when the microphone is refused.
  Future<bool> start();

  /// Stops and returns the clip, or null if nothing was recorded.
  Future<Uint8List?> stop();

  /// Stops and throws the clip away.
  Future<void> cancel();
}

final class RecordVoiceRecorder implements VoiceRecorder {
  final _recorder = AudioRecorder();
  String? _path;

  @override
  Future<bool> start() async {
    if (!await _recorder.hasPermission()) return false;
    final dir = await getTemporaryDirectory();
    _path = p.join(dir.path, 'dictation.wav');
    await _recorder.start(
      const RecordConfig(encoder: AudioEncoder.wav, sampleRate: 16000, numChannels: 1),
      path: _path!,
    );
    return true;
  }

  @override
  Future<Uint8List?> stop() async {
    final path = await _recorder.stop() ?? _path;
    if (path == null) return null;
    final file = File(path);
    if (!file.existsSync()) return null;
    final bytes = await file.readAsBytes();
    await file.delete();
    return bytes;
  }

  @override
  Future<void> cancel() async {
    await _recorder.cancel();
    final path = _path;
    if (path != null && File(path).existsSync()) await File(path).delete();
  }
}
```

```dart
  static const _maxRecording = Duration(minutes: 2);
  Duration? _recording;
  bool _transcribing = false;
  Timer? _clock;

  Future<void> _startDictation() async {
    if (!await _recorder.start()) {
      if (mounted) {
        showIrisToast(context, message: 'Iris needs the microphone. Allow it in Settings to dictate.');
      }
      return;
    }
    setState(() => _recording = Duration.zero);
    _clock = Timer.periodic(const Duration(seconds: 1), (_) {
      final next = (_recording ?? Duration.zero) + const Duration(seconds: 1);
      if (next >= _maxRecording) {
        unawaited(_stopDictation());
      } else {
        setState(() => _recording = next);
      }
    });

  Future<void> _stopDictation() async {
    _clock?.cancel();
    setState(() {
      _recording = null;
      _transcribing = true;
    });
    final clip = await _recorder.stop();
    final result = clip == null ? const Ok('') : await widget.backend.transcribe(clip);
    if (!mounted) return;
    setState(() => _transcribing = false);
    switch (result) {
      case Ok(value: ''):
        showIrisToast(context, message: "Didn't catch that. Try again a little closer.");
      case Ok(:final value):
        final before = _text.text.trimRight();
        _text.text = before.isEmpty ? value : '$before $value';
      case Err(:final failure):
        showIrisToast(context, message: "Couldn't transcribe: ${ChatController.describe(failure)}");
    }
  }

  Future<void> _cancelDictation() async {
    _clock?.cancel();
    setState(() => _recording = null);
```

```dart
Uint8List silentWav({required int seconds}) {
  const rate = 16000;
  final samples = rate * seconds;
  final data = ByteData(44 + samples * 2);
  void ascii(int at, String s) {
    for (var i = 0; i < s.length; i++) data.setUint8(at + i, s.codeUnitAt(i));
  }
  ascii(0, 'RIFF');
  data.setUint32(4, 36 + samples * 2, Endian.little);
  ascii(8, 'WAVE');
  ascii(12, 'fmt ');
  data
    ..setUint32(16, 16, Endian.little)
    ..setUint16(20, 1, Endian.little)
    ..setUint16(22, 1, Endian.little)
    ..setUint32(24, rate, Endian.little)
    ..setUint32(28, rate * 2, Endian.little)
    ..setUint16(32, 2, Endian.little)
    ..setUint16(34, 16, Endian.little);
  ascii(36, 'data');
  data.setUint32(40, samples * 2, Endian.little);
  return data.buffer.asUint8List();
}
```
