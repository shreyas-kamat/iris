# Phase 3 Implementation Plan: paging, Markdown, models, slash commands, profiles

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Phase 3 adds five things:
- Long conversations open on their newest messages, with "Show earlier messages" above them.
- Replies render as Markdown.
- The model can be seen and switched.
- Slash commands work, with suggestions while typing.
- A profile can be chosen.

**Architecture:**
- **Profile scoping.** `DashboardChat` is scoped to one profile, so the controller and screens never deal with profiles.
- **Backend.** It pages history in either direction (servers that count offsets from the oldest row or from the newest), lists conversations over REST, and wraps `model.options`, `config.set`, `commands.catalog`, `slash.exec` and `command.dispatch`.
- **Pure parsers.** New parsers turn those catalogues into view values.
- **Markdown.** `IrisMarkdown` draws `package:markdown`'s parse tree from design-system tokens.
- **State and controller.** They gain earlier-page loading, model switching and slash handling.

**Tech Stack:** Flutter 3.41.6 / Dart 3.11, flutter_riverpod 3.3. New in this phase: `markdown` 7.3.1 and `url_launcher` 6.3.3, both added in Task 3 only.

**Spec:** `docs/superpowers/specs/2026-10-13-phase3-design.md`. It has every verified wire shape; read it before Task 1.

## Global Constraints

- Mobile only (Android, iOS).
- The only new dependencies are `markdown` and `url_launcher`, added with `flutter pub add` in Task 3. Make no other `pubspec.yaml` changes.
- Nothing throws past `lib/data`. Every wire read goes through `Json`; never cast decoded JSON.
- **Profile scoping:**
  - A named profile is sent on every route and call that belongs to it: the `profile` query on `/api/sessions/...`, and the `profile` param on `session.resume` and `session.create`.
  - For `default`, those routes and calls get **no** `profile`.
  - The conversation list route `/api/profiles/sessions` always sends `profile`, including `default`. Without it, the server merges every profile's conversations.
- **Paging:**
  - A server that echoes `pagination.order == "latest"` counts offsets back from the newest row.
  - Any other server counts from the oldest row, so the newest page starts at `message_count - 120`.
- **Slash commands:**
  - Send `slash.exec` the command *without* its leading `/`.
  - Fall back to `command.dispatch` only when `slash.exec` returns an RPC error (`FailureKind.rejected`), never on a timeout.
- **Links** open only for `http`, `https` and `mailto`.
- **Code style:** match the existing code. That means a `library;` doc comment at the top of each file, `///` docs that say *why*, single quotes, relative imports in `lib/`, `package:iris/...` imports in `test/`, sorted imports, and `const` wherever possible.
- At the end of every task, `flutter analyze` prints `No issues found!` and `flutter test` prints `All tests passed!`.
- Commit messages end with `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`.

## Review Focus

1. **A long conversation must open on its newest messages on a server that pages from the oldest row.** Pinned by the Task 2 test "a dashboard that pages from the oldest opens on the newest page".
2. **A named profile's routes must carry `profile`, and the default profile's must not.** Otherwise history returns 404 for named profiles, and the list merges every profile. Pinned by the Task 2 tests "a named profile scopes its routes and calls" and "lists conversations over REST for the profile".
3. **A slash command must not be sent twice.** It falls back to `command.dispatch` only after a gateway rejection. Pinned by the Task 2 tests "a command slash.exec declines falls back to command.dispatch" and "a slash command that fails without a gateway answer is not dispatched again".
4. **A model switch Hermes wants confirmed must change nothing until it is confirmed.** Pinned by the Task 4 test "a switch that needs confirming changes nothing" and the Task 6 picker test.
5. **Half-written Markdown must render, not throw.** Replies stream token by token. Pinned by the Task 3 test "unfinished markup still renders".

```dart
/// Reads the dashboard's catalogues: profiles, conversation pages, models and
/// slash commands.
///
/// Shapes verified against Hermes 0.18.2 on 2026-10-13; see
/// `docs/superpowers/specs/2026-10-13-phase3-design.md`.
library;

import '../../core/json.dart';
import 'chat_models.dart';
import 'history_parser.dart';

abstract final class CatalogParser {
  /// `GET /api/profiles`.
  static List<AgentProfile> profiles(Json body) {
    final rows = body.isList ? body.list : body['profiles'].list;
    return [
      for (final row in rows) ?_profile(row),
    ];
  }

  static AgentProfile? _profile(Json row) {
    final name = HistoryParser.firstText(row, const ['name', 'id']);
    if (name == null) return null;
    return AgentProfile(
      name: name,
      isDefault: row['is_default'].boolean(),
      model: HistoryParser.firstText(row, const ['model']),
      provider: HistoryParser.firstText(row, const ['provider']),
      running: row['gateway_running'].boolean(),
    );
  }

  /// `GET /api/profiles/sessions`.
  static ConversationPage conversationPage(Json body) {
    final items = HistoryParser.conversations(body);
    return ConversationPage(
      items: items,
      total: body['total'].intOrNull ?? items.length,
    );
  }

  /// `model.options`.
  static ModelOptions modelOptions(Json result) => ModelOptions(
    model: HistoryParser.firstText(result, const ['model']),
    provider: HistoryParser.firstText(result, const ['provider']),
    providers: [
      for (final row in result['providers'].list) ?_provider(row),
    ],
  );

  static ModelProvider? _provider(Json row) {
    final slug = HistoryParser.firstText(row, const ['slug', 'id', 'name']);
    if (slug == null) return null;
    return ModelProvider(
      slug: slug,
      name: HistoryParser.firstText(row, const ['name', 'display_name']) ?? slug,
      models: [
        for (final model in row['models'].list) ?_modelId(model),
      ],
      isCurrent: row['is_current'].boolean(),
      authenticated: row['authenticated'].boolOrNull ?? true,
    );
  }

  /// A model entry: a bare id today, an object on some gateways.
  static String? _modelId(Json model) {
    final id =
        model.stringOrNull?.trim() ??
        HistoryParser.firstText(model, const ['id', 'name', 'model']);
    return id == null || id.isEmpty ? null : id;
  }

  /// `config.set` for the model. Hermes may echo the raw request, flags and
  /// all; only the model part is kept.
  static ModelSwitch modelSwitch(Json result, {required String requested}) {
    final raw = result['value'].string();
    final cut = raw.indexOf(' --');
    final value = (cut < 0 ? raw : raw.substring(0, cut)).trim();
    return ModelSwitch(
      model: value.isEmpty ? requested : value,
      confirmRequired: result['confirm_required'].boolean(),
      confirmMessage:
          HistoryParser.firstText(result, const ['confirm_message', 'warning']) ??
          '',
      deferred: result['deferred'].boolean(),
    );
  }

  /// `commands.catalog`: every command with its description, in the
  /// gateway's order, without duplicates.
  static List<SlashCommand> commands(Json result) {
    final seen = <String>{};
    final commands = <SlashCommand>[];
    for (final pair in result['pairs'].list) {
      final raw = pair.at(0).stringOrNull?.trim() ?? '';
      if (raw.isEmpty) continue;
      final name = raw.startsWith('/') ? raw : '/$raw';
      if (!seen.add(name)) continue;
      commands.add(
        SlashCommand(name: name, description: pair.at(1).string().trim()),
      );
    }
    return commands;
  }

  /// `slash.exec` or `command.dispatch`.
  static SlashOutcome slashOutcome(Json result) {
    if (result.stringOrNull case final plain?) {
      return SlashOutcome(kind: SlashKind.exec, text: plain);
    }
    final output = result.any(const ['output', 'message', 'notice']).string();
    return switch (result['type'].string().trim()) {
      'send' || 'skill' => SlashOutcome(
        kind: SlashKind.send,
        text: result.any(const ['message', 'output']).string(),
      ),
      'prefill' => SlashOutcome(
        kind: SlashKind.prefill,
        text: result.any(const ['message', 'output']).string(),
        notice: result['notice'].string(),
      ),
      'alias' => SlashOutcome(
        kind: SlashKind.alias,
        text: output,
        target:
            HistoryParser.firstText(result, const ['target', 'command', 'name']) ??
            '',
      ),
      _ => SlashOutcome(kind: SlashKind.exec, text: output),
    };
  }
}
```

```dart
/// Conversations on one dashboard: listing, reading, sending, answering.
///
/// [ChatBackend] is the seam the chat screen depends on, so the screen is
/// tested against a scripted fake. [DashboardChat] is the real one: the live
/// socket for anything live, and REST for stored history and lists — the split
/// Hermes Desktop and Conduit both use, because a long transcript sent over the
/// socket would hold up every event queued behind it.
library;

import 'dart:async';
import 'dart:math' as math;

import '../../core/failure.dart';
import '../../core/json.dart';
import '../../core/result.dart';
import '../rpc/dashboard_session.dart';

/// Where a page of stored history starts, in the server's own terms.
final class HistoryCursor {
  const HistoryCursor({required this.offset, required this.fromNewest});

  /// Rows to skip.
  final int offset;

  /// Whether [offset] counts back from the newest row (a dashboard that
  /// honours `order=latest`) or forward from the oldest (Hermes 0.18.2).
  final bool fromNewest;
}

/// One page of stored history.
final class HistoryPage {
  const HistoryPage({required this.items, this.earlier});

  /// Oldest first.
  final List<TranscriptItem> items;

  /// Where the page before this one starts; null at the beginning.
  final HistoryCursor? earlier;
}

/// A conversation Iris just created.
final class NewConversation {
  const NewConversation({required this.runtimeId, required this.storedId});

  /// What live calls and events use.
  final String runtimeId;

  /// What history and the conversation list use.
  final String storedId;
}

/// A stored conversation, attached to the live socket.
final class ResumedConversation {
  const ResumedConversation({
    required this.runtimeId,
    this.running = false,
    this.pending = const [],
    this.model,
    this.provider,
  });

  final String runtimeId;

  /// A turn was already in progress — started elsewhere, or before a
  /// reconnect.
  final bool running;

  /// Approvals and questions still waiting for an answer.
  final List<ChatEvent> pending;

  /// The model the conversation runs on, when the gateway says.
  final String? model;
  final String? provider;
}

abstract interface class ChatBackend {
  /// Events and decisions for every live conversation; callers keep the ones
  /// for their own session.
  Stream<ChatEvent> get events;

  /// Fires each time the live link comes back after a drop. A runtime
  /// session belongs to the socket that created or resumed it, so an open
  /// conversation has to resume again or its events go nowhere.
  Stream<void> get reconnected;

  /// A page of this profile's conversations, newest first, from [offset].
  Future<Result<ConversationPage>> conversations(int offset);

  /// Every agent profile on the dashboard.
  Future<Result<List<AgentProfile>>> profiles();

  /// The newest page of [storedId]'s transcript, or the page before
  /// [before].
  Future<Result<HistoryPage>> history(String storedId, {HistoryCursor? before});

  Future<Result<ResumedConversation>> resume(String storedId);

  Future<Result<NewConversation>> create();

  Future<Result<void>> submit(String runtimeId, String text);

  Future<Result<void>> interrupt(String runtimeId);

  Future<Result<void>> answerApproval(ApprovalRequest request, String choice);

  Future<Result<void>> answerClarify(
    ClarifyRequest request,
    ClarifyQuestion question,
    String answer,
  );

  /// The models the live session — or, without one, the profile — can use.
  Future<Result<ModelOptions>> modelOptions({String? runtimeId});

  /// Switches the live session's model. A switch Hermes wants confirmed
  /// changes nothing and says so; call again with [confirmed] once the
  /// person agrees.
  Future<Result<ModelSwitch>> switchModel(
    String runtimeId, {
    required String model,
    required String provider,
    required bool confirmed,
  });

  /// Every slash command the gateway knows.
  Future<Result<List<SlashCommand>>> commands();

  /// Runs [command] (with or without its leading slash) in the live session.
  Future<Result<SlashOutcome>> runSlash(String runtimeId, String command);
}

final class DashboardChat implements ChatBackend {
  DashboardChat(this._session, {this.profile = 'default'})
    : _live = _session.state.phase == LinkPhase.live,
      _everLive = _session.state.phase == LinkPhase.live {
    _linkSubscription = _session.states.listen(_onLink);
    _eventSubscription = _session.events.listen((event) {
      if (ChatEvent.fromEvent(event) case final parsed?) _events.add(parsed);
    });
    _requestSubscription = _session.serverRequests.listen((request) {
      if (ChatEvent.fromServerRequest(request) case final parsed?) {
        _events.add(parsed);
      }
    });
  }

  /// Rows per history page, as Hermes Desktop asks for.
  static const historyPage = 120;

  /// Conversations per list page.
  static const conversationPage = 50;

  /// Long enough for a busy gateway to accept a turn. The reply itself
  /// streams as events, not as this call's result.
  static const submitTimeout = Duration(seconds: 180);

  /// The agent profile this backend reads and writes.
  final String profile;

  final DashboardSession _session;
  final _events = StreamController<ChatEvent>.broadcast();
  late final StreamSubscription<RpcEvent> _eventSubscription;
  late final StreamSubscription<RpcServerRequest> _requestSubscription;
  late final StreamSubscription<LinkState> _linkSubscription;
  final _reconnected = StreamController<void>.broadcast();
  bool _live;
  bool _everLive;

  @override
  Stream<ChatEvent> get events => _events.stream;

  @override
  Stream<void> get reconnected => _reconnected.stream;

  void _onLink(LinkState state) {
    final live = state.phase == LinkPhase.live;
    if (live && !_live && _everLive) _reconnected.add(null);
    if (live) _everLive = true;
    _live = live;
  }

  /// [values] plus this profile, for a route or call that belongs to it. The
  /// default profile is left implicit, as the dashboard expects; a named
  /// profile's sessions answer 404 without it.
  Map<String, Object?> _scoped(Map<String, Object?> values) =>
      profile == 'default' ? values : {...values, 'profile': profile};

  @override
  Future<Result<HistoryPage>> history(
    String storedId, {
    HistoryCursor? before,
  }) async {
    final path = '/api/sessions/${Uri.encodeComponent(storedId)}';
    if (before != null) return _earlier(path, before);
    // Ask for the newest page. A dashboard that honours `order=latest` echoes
    // it and counts offsets back from the newest row. One that does not —
    // Hermes 0.18.2 — counts from the oldest, so its newest page starts at
    // `message_count - historyPage`.
    final first = await _messages(path, offset: 0, limit: historyPage);
    switch (first) {
      case Err(:final failure):
        return Err(failure);
      case Ok(value: final body):
        final rows = body['messages'].list.length;
        if (body['pagination']['order'].stringOrNull == 'latest') {
          return Ok(
            HistoryPage(
              items: HistoryParser.transcript(body),
              earlier: rows < historyPage
                  ? null
                  : const HistoryCursor(offset: historyPage, fromNewest: true),
            ),
          );
        }
        final all = HistoryPage(items: HistoryParser.transcript(body));
        if (rows < historyPage) return Ok(all);
        final row = await _session.connection.client.get(
          path,
          query: _scoped(const {}),
        );
        final count = row.valueOrNull?['message_count'].intOrNull;
        // Without a count the end cannot be found; the oldest page beats
        // nothing.
        if (count == null || count <= historyPage) return Ok(all);
        final start = count - historyPage;
        final tail = await _messages(path, offset: start, limit: historyPage);
        return tail.map(
          (page) => page['messages'].list.isEmpty
              ? all
              : HistoryPage(
                  items: HistoryParser.transcript(page),
                  earlier: HistoryCursor(offset: start, fromNewest: false),
                ),
        );
    }
  }

  Future<Result<HistoryPage>> _earlier(
    String path,
    HistoryCursor before,
  ) async {
    if (before.fromNewest) {
      final page = await _messages(
        path,
        offset: before.offset,
        limit: historyPage,
      );
      return page.map((body) {
        final rows = body['messages'].list.length;
        return HistoryPage(
          items: HistoryParser.transcript(body),
          earlier: rows < historyPage
              ? null
              : HistoryCursor(offset: before.offset + rows, fromNewest: true),
        );
      });
    }
    if (before.offset <= 0) return const Ok(HistoryPage(items: []));
    final start = math.max(0, before.offset - historyPage);
    final page = await _messages(
      path,
      offset: start,
      limit: before.offset - start,
    );
    return page.map(
      (body) => HistoryPage(
        items: HistoryParser.transcript(body),
        earlier: start == 0
            ? null
            : HistoryCursor(offset: start, fromNewest: false),
      ),
    );
  }

  Future<Result<Json>> _messages(
    String path, {
    required int offset,
    required int limit,
  }) => _session.connection.client.get(
    '$path/messages',
    query: _scoped({
      'limit': limit,
      'offset': offset,
      'order': 'latest',
      'include_compacted': 'true',
    }),
  );

  @override
  Future<Result<ResumedConversation>> resume(String storedId) async {
    final result = await _session.call(
      'session.resume',
      params: _scoped({
        'session_id': storedId,
        'cols': 96,
        'source': 'desktop',
        'omit_messages': true,
      }),
    );
    return result.map((json) {
      final pending = <ChatEvent>[];
      // Decisions asked before Iris attached are re-announced here, under
      // their original server request ids.
      for (final entry in json['open_requests'].list) {
        final method = entry['method'].stringOrNull;
        final id = entry['id'].stringOrNull;
        if (method == null || id == null) continue;
        final request = RpcServerRequest(
          id: id,
          method: method,
          params: entry['params'],
        );
        if (ChatEvent.fromServerRequest(request) case final parsed?) {
          pending.add(parsed);
        }
      }
      final info = json['info'];
      return ResumedConversation(
        runtimeId:
            HistoryParser.firstText(json, const ['session_id']) ?? storedId,
        running: json['running'].boolOrNull ?? info['running'].boolean(),
        pending: pending,
        model: HistoryParser.firstText(info, const ['model']),
        provider: HistoryParser.firstText(info, const ['provider']),
      );
    });
  }

  @override
  Future<Result<NewConversation>> create() async {
    final result = await _session.call(
      'session.create',
      params: _scoped({'cols': 96, 'source': 'desktop'}),

    },
  )).map((_) {});

  @override
  Future<Result<void>> answerClarify(
    ClarifyRequest request,
    ClarifyQuestion question,
    String answer,
  ) async {
    if (!request.isServerRequest) {
      return (await _session.call(
        'clarify.respond',
        params: {
          'request_id': request.requestId,
          'answer': answer,
          if (!question.synthetic) 'question_id': question.id,
        },
      )).map((_) {});
    }
    if (!question.synthetic) {
      // One question of a batch. Each is locked on its own; the last lock
      // resolves the whole request.
      return (await _session.call(
        'clarify.lock',
        params: {
          'request_id': request.requestId,
          'question_id': question.id,
          'answer': answer,
        },
      )).map((_) {});
    }
    // A single question is answered with the response frame itself.
    return _session.replyToServerRequest(request.requestId, {'answer': answer})
        ? const Ok(null)
        : const Err(
            IrisFailure.offline(message: 'Not connected to the dashboard.'),
          );
  }

  @override
  Future<Result<SlashOutcome>> runSlash(
    String runtimeId,
    String command,
  ) async {
    final cleaned = command.replaceFirst(RegExp('^/+'), '').trim();
    final result = await _session.call(
      'slash.exec',
      params: {'session_id': runtimeId, 'command': cleaned},
    );
    // Only a gateway answer means slash.exec declined to run it. A timeout or
    // a dropped socket may mean it IS running, and dispatching it again could
    // run it twice.
    if (result case Err(:final failure)
        when failure.kind == FailureKind.rejected) {
      final space = cleaned.indexOf(' ');
      final dispatched = await _session.call(
        'command.dispatch',
        params: {
          'session_id': runtimeId,
          'name': space < 0 ? cleaned : cleaned.substring(0, space),
          'arg': space < 0 ? '' : cleaned.substring(space + 1).trim(),
        },
      );
      // When slash.exec pointed at command.dispatch, dispatch's own failure is
      // the real one; otherwise slash.exec's rejection is.
      if (dispatched is Err &&
          !(failure.message ?? '').contains('command.dispatch')) {
        return Err(failure);
      }
      return dispatched.map(CatalogParser.slashOutcome);
    }
    return result.map(CatalogParser.slashOutcome);
  }

  Future<void> dispose() async {
    await _eventSubscription.cancel();
    await _requestSubscription.cancel();
    await _linkSubscription.cancel();
    await _events.close();
    await _reconnected.close();
  }
}
```

```dart
  /// afresh on every build, so the previous build's are disposed first.
  final List<TapGestureRecognizer> _recognizers = [];

  void _clearRecognizers() {
    for (final recognizer in _recognizers) {
      recognizer.dispose();
    }
    _recognizers.clear();
  }

  @override
  void dispose() {
    _clearRecognizers();
    super.dispose();
  }

  @override
  Widget build(BuildContext context) {
    _clearRecognizers();
    final nodes = md.Document(
      extensionSet: md.ExtensionSet.gitHubFlavored,
      encodeHtml: false,
    ).parse(widget.data);
    final renderer = _Renderer(context.iris, widget.onTapLink, _recognizers);
    return Column(
      crossAxisAlignment: CrossAxisAlignment.start,
      mainAxisSize: MainAxisSize.min,
      children: _Renderer.spaced(renderer.blocks(nodes), IrisSpace.sm),
    );
  }

final class _Renderer {
  _Renderer(this.theme, this.onTapLink, this.recognizers);

  final IrisThemeData theme;
  final ValueChanged<String>? onTapLink;
  final List<TapGestureRecognizer> recognizers;

  static const _blockTags = {
    'p',
    'h1',
    'h2',
    'h3',
    'h4',
    'h5',
    'h6',
    'ul',
    'ol',
    'blockquote',
    'pre',
    'hr',
    'table',
  };

  TextStyle get body =>
      theme.typography.bodyLarge.copyWith(color: theme.palette.ink);

  TextStyle _heading(String tag) => switch (tag) {
    'h1' || 'h2' => theme.typography.title.copyWith(color: theme.palette.ink),
    'h3' => theme.typography.heading.copyWith(color: theme.palette.ink),
    _ => body.copyWith(fontWeight: FontWeight.w600),
  };

  static List<Widget> spaced(List<Widget> widgets, double gap) => [
    for (var i = 0; i < widgets.length; i++) ...[
      if (i > 0) SizedBox(height: gap),
      widgets[i],
    ],
  ];

  List<Widget> blocks(List<md.Node> nodes) => [
    for (final node in nodes) ?block(node),
  ];

  Widget? block(md.Node node) {
    if (node is md.Text) {
      return node.text.trim().isEmpty ? null : _rich(inline([node], body));
    }
    if (node is! md.Element) return null;
    return switch (node.tag) {
      'h1' || 'h2' || 'h3' || 'h4' || 'h5' || 'h6' => _rich(
        inline(node.children, _heading(node.tag)),
      ),
      'ul' || 'ol' => list(node),
      'blockquote' => quote(node),
      'pre' => code(node),
      'hr' => Divider(
        height: IrisSpace.md,
        thickness: IrisStroke.hairline,
        color: theme.palette.line,
      ),
      'table' => table(node),
      _ => _rich(inline(node.children, body)),
    };
  }

  Widget _rich(List<InlineSpan> spans) => Text.rich(TextSpan(children: spans));

  List<InlineSpan> inline(
    List<md.Node>? nodes,
    TextStyle style, [
    GestureRecognizer? link,
  ]) {
    final spans = <InlineSpan>[];
    for (final node in nodes ?? const <md.Node>[]) {
      if (node is md.Text) {
        spans.add(TextSpan(text: node.text, style: style, recognizer: link));
      } else if (node is md.Element) {
        spans.addAll(_element(node, style, link));
      }
    }
    return spans;
  }

  List<InlineSpan> _element(
    md.Element node,
    TextStyle style,
    GestureRecognizer? link,
  ) {
    switch (node.tag) {
      case 'strong':
        return inline(
          node.children,
          style.copyWith(fontWeight: FontWeight.w600),
          link,
        );
      case 'em':
        return inline(
          node.children,
          style.copyWith(fontStyle: FontStyle.italic),
          link,
        );
      case 'del':
        return inline(
          node.children,
          style.copyWith(decoration: TextDecoration.lineThrough),
          link,
        );
      case 'code':
        return [
          TextSpan(
            text: node.textContent,
            style: _inlineCode(style),
            recognizer: link,
          ),
        ];
      case 'a':
        return inline(
          node.children,
          style.copyWith(
            color: theme.palette.accent,
            decoration: TextDecoration.underline,
            decorationColor: theme.palette.accent,
          ),
          _link(node.attributes['href']) ?? link,
        );
      case 'br':
        return const [TextSpan(text: '\n')];
      case 'img':
        return [
          TextSpan(
            text: node.attributes['alt'] ?? 'image',
            style: style.copyWith(
              fontStyle: FontStyle.italic,
              color: theme.palette.inkMuted,
            ),
          ),
        ];
      case 'input':
        // A task-list checkbox.
        return [
          TextSpan(
            text: node.attributes.containsKey('checked') ? '☑ ' : '☐ ',
            style: style,
          ),
        ];
      default:
        return inline(node.children, style, link);
    }
  }

  TextStyle _inlineCode(TextStyle around) => theme.typography.code.copyWith(
    fontSize: (around.fontSize ?? 16) * 0.9,
    color: theme.palette.ink,
    backgroundColor: theme.palette.surfaceSunken,
  );

  GestureRecognizer? _link(String? href) {
    final tap = onTapLink;
    if (href == null || href.isEmpty || tap == null) return null;
    final recognizer = TapGestureRecognizer()..onTap = () => tap(href);
    recognizers.add(recognizer);
    return recognizer;
  }

  Widget list(md.Element node) {
    final ordered = node.tag == 'ol';
    var number = int.tryParse(node.attributes['start'] ?? '') ?? 1;
    final rows = <Widget>[];
    for (final child in node.children ?? const <md.Node>[]) {
      if (child is! md.Element || child.tag != 'li') continue;
      rows.add(
        Row(
          crossAxisAlignment: CrossAxisAlignment.start,
          children: [
            SizedBox(
              width: ordered ? 28 : 18,
              child: Text(
                ordered ? '${number++}.' : '•',
                style: body.copyWith(color: theme.palette.inkMuted),
              ),
            ),
            Expanded(
              child: Column(
                crossAxisAlignment: CrossAxisAlignment.start,
                children: spaced(_item(child), IrisSpace.xxs),
              ),
            ),
          ],
        ),
      );
    }
    return Column(
      crossAxisAlignment: CrossAxisAlignment.start,
      children: spaced(rows, IrisSpace.xs),
    );
  }

  /// A list item's contents. A tight item holds inline nodes directly, a loose
  /// one holds paragraphs, and either can hold a nested list.
  List<Widget> _item(md.Element item) {
    final widgets = <Widget>[];
    final run = <md.Node>[];
    void flush() {
      if (run.isEmpty) return;
      widgets.add(_rich(inline(List.of(run), body)));
      run.clear();
    }

    for (final child in item.children ?? const <md.Node>[]) {
      if (child is md.Element && _blockTags.contains(child.tag)) {
        flush();
        if (block(child) case final widget?) widgets.add(widget);
      } else {
        run.add(child);
      }
    }
    flush();
    return widgets;
  }

  Widget quote(md.Element node) => DecoratedBox(
    decoration: BoxDecoration(
      border: Border(
        left: BorderSide(
          color: theme.palette.lineStrong,
          width: IrisStroke.ring,
        ),
      ),
    ),
    child: Padding(
      padding: const EdgeInsets.only(left: IrisSpace.md),
      child: Column(
        crossAxisAlignment: CrossAxisAlignment.start,
        children: spaced(
          blocks(node.children ?? const <md.Node>[]),
          IrisSpace.sm,
        ),
      ),
    ),
  );

  Widget code(md.Element node) {
    final text = node.textContent.replaceFirst(RegExp(r'\n$'), '');
    return SizedBox(
      width: double.infinity,
      child: DecoratedBox(
        decoration: BoxDecoration(
          color: theme.palette.surfaceSunken,
          borderRadius: const BorderRadius.all(IrisRadius.xs),
        ),
        child: SingleChildScrollView(
          scrollDirection: Axis.horizontal,
          padding: const EdgeInsets.all(IrisSpace.sm),
          child: Text(
            text,
            style: theme.typography.codeSmall.copyWith(
              color: theme.palette.ink,
            ),
          ),
        ),
      ),
    );
  }

  Widget table(md.Element node) {
    final rows = <List<Widget>>[];
    void collect(md.Element element) {
      for (final child in element.children ?? const <md.Node>[]) {
        if (child is! md.Element) continue;
        if (child.tag == 'tr') {
          rows.add([
            for (final cell in child.children ?? const <md.Node>[])
              if (cell is md.Element)
                Padding(
                  padding: const EdgeInsets.symmetric(
                    horizontal: IrisSpace.sm,
                    vertical: IrisSpace.xs,
                  ),
                  child: _rich(
                    inline(
                      cell.children,
                      cell.tag == 'th'
                          ? body.copyWith(fontWeight: FontWeight.w600)
                          : body,
                    ),
                  ),
                ),
          ]);
        } else {
          collect(child);
        }
      }
    }

    collect(node);
    if (rows.isEmpty) return const SizedBox.shrink();
    // A Table needs every row the same length; a ragged table is padded.
    final width = rows.map((row) => row.length).reduce(math.max);
    if (width == 0) return const SizedBox.shrink();
    return SingleChildScrollView(
      scrollDirection: Axis.horizontal,
      child: Table(
        defaultColumnWidth: const IntrinsicColumnWidth(),
        border: TableBorder.all(
          color: theme.palette.line,
          width: IrisStroke.hairline,
        ),
        children: [
          for (final row in rows)
            TableRow(
              children: [
                ...row,
                for (var i = row.length; i < width; i++)
                  const SizedBox.shrink(),
              ],
            ),
        ],
      ),
    );
  }
}
```

```dart
/// One open conversation's state, and how events change it.
///
/// Pure: `apply` takes an event and returns the next state, so every streaming
/// edge case is a plain unit test rather than a widget test.
library;

import 'package:flutter/foundation.dart';

import '../../core/failure.dart';
import '../../data/chat/chat_backend.dart';
import '../../data/chat/chat_event.dart';
import '../../data/chat/chat_models.dart';

enum ChatPhase {
  /// Reading the stored transcript.
  loading,

  /// Showing it; sending works.
  ready,

  /// The transcript could not be read.
  failed,
}

/// What the agent is doing in this conversation right now.
enum TurnPhase { idle, thinking, streaming, working, waiting }

@immutable
final class ChatState {
  const ChatState({
    this.phase = ChatPhase.loading,
    this.items = const [],
    this.turn = TurnPhase.idle,
    this.approvals = const [],
    this.questions = const [],
    this.title,
    this.failure,
    this.earlier,
    this.loadingEarlier = false,
    this.model,
    this.provider,
    this.commands = const [],
  });

  final ChatPhase phase;
  final List<TranscriptItem> items;
  final TurnPhase turn;
  final List<ApprovalRequest> approvals;
  final List<ClarifyRequest> questions;
  final String? title;

  /// Why the transcript could not be read, when [phase] is failed.
  final IrisFailure? failure;

  /// Where the page before the oldest shown message starts; null when the
  /// whole conversation is shown.
  final HistoryCursor? earlier;
  final bool loadingEarlier;

  /// The model the conversation runs on, when known.
  final String? model;
  final String? provider;

  /// The gateway's slash commands, once read.
  final List<SlashCommand> commands;

  bool get running => turn != TurnPhase.idle;

  ChatState copyWith({
    ChatPhase? phase,
    List<TranscriptItem>? items,
    TurnPhase? turn,
    List<ApprovalRequest>? approvals,
    List<ClarifyRequest>? questions,
    String? title,
    IrisFailure? failure,
    HistoryCursor? earlier,
    bool? loadingEarlier,
    String? model,
    String? provider,
    List<SlashCommand>? commands,
  }) => ChatState(
    phase: phase ?? this.phase,
    items: items ?? this.items,
    turn: turn ?? this.turn,
    approvals: approvals ?? this.approvals,
    questions: questions ?? this.questions,
    title: title ?? this.title,
    failure: failure ?? this.failure,
    earlier: earlier ?? this.earlier,
    loadingEarlier: loadingEarlier ?? this.loadingEarlier,
    model: model ?? this.model,
    provider: provider ?? this.provider,
    commands: commands ?? this.commands,
  );

  /// The state after [event].
  ChatState apply(ChatEvent event) => switch (event) {
    MessageStarted() => copyWith(
      items: _withLive(items),
      turn: TurnPhase.thinking,
    ),
    TextDelta(:final text) => copyWith(
      items: _appendLive(items, text: text),
      turn: TurnPhase.streaming,
    ),
    ReasoningDelta(:final text) => copyWith(
      items: _appendLive(items, reasoning: text),
      turn: turn == TurnPhase.streaming ? turn : TurnPhase.thinking,
    ),
    MessageCompleted(:final content, :final reasoning) => copyWith(
      items: _completed(items, content, reasoning),
      turn: _waitingOr(TurnPhase.idle),

    ToolStarted(:final toolId, :final name, :final input) => copyWith(
      items: [
        ..._settled(items),
        ToolCall(
          id: toolId ?? 'tool-${items.length}',
          name: name,
          arguments: input,
          status: ToolStatus.running,
        ),
      ],
      turn: TurnPhase.working,
    ),
    final ToolCompleted done => copyWith(
      items: _toolDone(items, done),
      turn: _waitingOr(TurnPhase.thinking),
    ),
    TurnFailed(:final message) => withError(message),
    TurnInterrupted() => copyWith(
      items: [
        ..._settled(items),
        Notice(id: 'notice-${items.length}', text: 'Stopped.'),
      ],
      turn: TurnPhase.idle,
    ),
    BusyChanged(:final busy) =>
      busy
          ? copyWith(turn: turn == TurnPhase.idle ? TurnPhase.thinking : turn)
          : copyWith(items: _settled(items), turn: _waitingOr(TurnPhase.idle)),
    TitleChanged(:final title) => copyWith(title: title),
    ModelChanged(:final model, :final provider) => copyWith(
      model: model,
      provider: provider,

    ClarifyAsked(:final request) => withQuestion(request),

      copyWith(
        approvals: [
          for (final approval in approvals)
            if (!approval.matches(requestId)) approval,
        ],
        questions: [
          for (final question in questions)
            if (question.requestId != requestId) question,
        ],
      ),
    ),
  };

  ChatState withNewestPage(
    List<TranscriptItem> page,
    HistoryCursor? earlier,

    phase: ChatPhase.ready,
    items: page,
    turn: turn,
    approvals: approvals,
    questions: questions,
    title: title,
    earlier: earlier,
    model: model,
    provider: provider,
    commands: commands,
  );

    List<TranscriptItem> page,
    HistoryCursor? earlier,
  ) => ChatState(
    phase: phase,
    items: [...page, ...items],
    turn: turn,
    approvals: approvals,
    questions: questions,
    title: title,
    failure: failure,
    earlier: earlier,
    model: model,
    provider: provider,
    commands: commands,
  );

  /// The person's message, shown at once.
  ChatState withUserTurn(String text) => copyWith(
    items: [
      ..._settled(items),
      UserTurn(id: 'local-${items.length}', text: text),
    ],
    turn: TurnPhase.thinking,
  );

  /// A failure, shown inline; the turn ends unless a decision is waiting.
  ChatState withError(String message) => copyWith(
    items: [
      ..._settled(items),
      Notice(id: 'notice-${items.length}', text: message, isError: true),
    ],
    turn: _waitingOr(TurnPhase.idle),
  );

  /// A line that is not a turn — a command's output, a model change. The
  /// turn carries on as it was; blank text adds nothing.

            ..._settled(items),
            Notice(id: 'notice-${items.length}', text: text.trim()),
          ],

      copyWith(items: _settled(items), turn: _waitingOr(TurnPhase.idle));

  ChatState withApproval(ApprovalRequest request) => copyWith(

      for (final approval in approvals)
        if (!_sameApproval(approval, request)) approval,
      request,

    turn: TurnPhase.waiting,

      approvals: [
        for (final approval in approvals)
          if (!_sameApproval(approval, request)) approval,

    questions: [
      for (final question in questions)
        if (question.requestId != request.requestId) question,
      request,
    ],
    turn: TurnPhase.waiting,
  );

  ChatState withoutQuestion(ClarifyRequest request, ClarifyQuestion question) {
    final remaining = request.without(question.id);
    return _decided(
      copyWith(
        questions: [
          for (final pending in questions)
            if (pending.requestId != request.requestId)
              pending
            else if (remaining.questions.isNotEmpty)
              remaining,
        ],
      ),
    );
  }

  TurnPhase _waitingOr(TurnPhase phase) =>
      approvals.isNotEmpty || questions.isNotEmpty ? TurnPhase.waiting : phase;

  /// After a decision: back to thinking once nothing is waiting.
  static ChatState _decided(ChatState next) =>
      next.turn == TurnPhase.waiting &&
          next.approvals.isEmpty &&
          next.questions.isEmpty
      ? next.copyWith(turn: TurnPhase.thinking)
      : next;

  static bool _sameApproval(ApprovalRequest a, ApprovalRequest b) =>
      identical(a, b) ||
      (a.serverRequestId != null && a.serverRequestId == b.serverRequestId) ||
      (a.queueId != null && a.queueId == b.queueId);

  /// [items] with a live assistant turn at the end, creating one if needed.
  static List<TranscriptItem> _withLive(List<TranscriptItem> items) {
    final last = items.isEmpty ? null : items.last;
    if (last is AssistantTurn && last.streaming) return items;
    return [
      ...items,
      AssistantTurn(id: 'live-${items.length}', text: '', streaming: true),
    ];
  }

  static List<TranscriptItem> _appendLive(
    List<TranscriptItem> items, {
    String text = '',
    String reasoning = '',
  }) {
    final withLive = _withLive(items);
    final live = withLive.last;
    if (live is! AssistantTurn) return withLive;
    return [
      ...withLive.sublist(0, withLive.length - 1),
      live.copyWith(
        text: live.text + text,
        reasoning: live.reasoning + reasoning,
      ),
    ];
  }

  /// [items] with the live assistant turn finished: kept if it says
  /// anything, dropped if it never did.
  static List<TranscriptItem> _settled(List<TranscriptItem> items) {
    final last = items.isEmpty ? null : items.last;
    if (last is! AssistantTurn || !last.streaming) return items;
    final rest = items.sublist(0, items.length - 1);
    return last.isEmpty ? rest : [...rest, last.copyWith(streaming: false)];
  }

  static List<TranscriptItem> _completed(
    List<TranscriptItem> items,
    String? content,
    String? reasoning,
  ) {
    final last = items.isEmpty ? null : items.last;
    if (last is AssistantTurn && last.streaming) {
      final rest = items.sublist(0, items.length - 1);
      // The deltas win. The complete event's text fills in only when no text
      // arrived in this turn at all, because it may repeat what was said
      // before a tool call.
      final finished = last.copyWith(
        text: last.text.trim().isEmpty && _has(content) && !_turnHasText(rest)
            ? content
            : null,
        reasoning: last.reasoning.trim().isEmpty && _has(reasoning)
            ? reasoning
            : null,
        streaming: false,
      );
      return finished.isEmpty ? rest : [...rest, finished];
    }
    if (!_has(content) || _turnHasText(items)) return items;
    return [
      ...items,
      AssistantTurn(
        id: 'live-${items.length}',
        text: content!,
        reasoning: reasoning ?? '',
      ),
    ];
  }

  static bool _has(String? text) => text != null && text.trim().isNotEmpty;

  /// Whether the agent already said something since the person last spoke.
  static bool _turnHasText(List<TranscriptItem> items) {
    for (final item in items.reversed) {
      if (item is UserTurn) return false;
      if (item is AssistantTurn && item.text.trim().isNotEmpty) return true;
    }
    return false;
  }

  static List<TranscriptItem> _toolDone(
    List<TranscriptItem> items,
    ToolCompleted done,
  ) {
    final status = done.failed ? ToolStatus.failed : ToolStatus.done;
    final toolId = done.toolId;
    var at = toolId == null
        ? null
        : _lastToolIndex(items, (call) => call.id == toolId);
    at ??= _lastToolIndex(
      items,
      (call) => call.status == ToolStatus.running && call.name == done.name,
    );
    if (at != null) {
      final call = items[at];
      if (call is ToolCall) {
        return [
          ...items.sublist(0, at),
          call.copyWith(output: done.output, status: status),
          ...items.sublist(at + 1),
        ];
      }
    }
    return [
      ..._settled(items),
      ToolCall(
        id: toolId ?? 'tool-${items.length}',
        name: done.name,
        output: done.output,
        status: status,
      ),
    ];
  }

  static int? _lastToolIndex(
    List<TranscriptItem> items,
    bool Function(ToolCall call) test,
  ) {
    for (var i = items.length - 1; i >= 0; i--) {
      final item = items[i];
      if (item is ToolCall && test(item)) return i;
    }
    return null;
  }
}
```

```dart
/// One open conversation: loads it, follows its live events, sends, stops,
/// answers, pages back, switches model and runs slash commands.
///
/// A [ValueNotifier] rather than a provider: a conversation lives exactly as
/// long as its screen, and the screen owns it.

import 'package:flutter/foundation.dart';

  StreamSubscription<void>? _reconnects;

  /// Starts following events, then reads the transcript and attaches to it.
  Future<void> open() async {
    _subscription ??= _backend.events.listen(_onEvent);
    _reconnects ??= _backend.reconnected.listen((_) => unawaited(_reattach()));
    final storedId = _storedId;
    if (storedId == null) return;
    _update(
      ChatState(
        title: value.title,
        model: value.model,
        provider: value.provider,
        commands: value.commands,
      ),
    );
    switch (await _backend.history(storedId)) {
      case Err(:final failure):
        _update(value.copyWith(phase: ChatPhase.failed, failure: failure));
        return;
      case Ok(value: final page):
        _update(value.withNewestPage(page.items, page.earlier));
    }
    if (_disposed) return;
    switch (await _backend.resume(storedId)) {
      case Err(:final failure):
        // Readable but not live: the history stays, and the transcript says
        // why sending may not work.
        _update(value.withError(describe(failure)));
      case Ok(value: final resumed):
        _runtimeId = resumed.runtimeId;
        var next = value.copyWith(
          turn: resumed.running ? TurnPhase.thinking : null,
          model: resumed.model,
          provider: resumed.provider,
        );
        for (final event in resumed.pending) {
          next = next.apply(event);
        }
        _update(next);
    }
  }

  /// After a reconnect. The old runtime session went with the old socket, so
  /// its events and any Stop would go nowhere: read what was said while away,
  /// then attach again. The old runtime id is kept until the new one arrives,
  /// so a send in between does not start a second conversation.
  Future<void> _reattach() async {
    final storedId = _storedId;
    if (storedId == null || _disposed) return;
    final history = await _backend.history(storedId);
    if (_disposed) return;
    if (history case Ok(value: final page)) {
      _update(value.withNewestPage(page.items, page.earlier));
    }
    final resumed = await _backend.resume(storedId);
    if (_disposed) return;
    switch (resumed) {
      case Err(:final failure):
        _update(value.withError(describe(failure)));
      case Ok(value: final again):
        _runtimeId = again.runtimeId;
        // Decisions are re-announced by the resume, so stale cards go.
        var next = value.copyWith(
          turn: again.running

              : TurnPhase.idle,

          questions: const [],
          model: again.model,
          provider: again.provider,
        );

          next = next.apply(event);
        }
        _update(next);
    }

  /// Text that starts with a slash runs as a command.
  Future<void> send(String text) async {

    if (runtimeId == null) return;

      await _slash(runtimeId, trimmed, depth: 0);
    } else {

    }

    if (sent case Err(:final failure)) {
      _update(value.withError(describe(failure)));
    }

  /// Runs a slash command and does what it asks: show output, send a prompt,
  /// fill the composer, or follow an alias — at most three deep, so an alias
  /// loop cannot spin forever.
  Future<void> _slash(
    String runtimeId,
    String command, {
    required int depth,
  }) async {
    final result = await _backend.runSlash(runtimeId, command);
    if (_disposed) return;
    switch (result) {
      case Err(:final failure):
        _update(value.withError(describe(failure)));
      case Ok(value: final outcome):
        switch (outcome.kind) {
          case SlashKind.exec:
            final output = outcome.text.trim();
            _update(value.withNotice(output.isEmpty ? 'Done.' : output).settled());
          case SlashKind.send:
            final prompt = outcome.text.trim();
            if (prompt.isEmpty) {
              _update(value.settled());
            } else {
              _update(value.withUserTurn(prompt));
              await _submit(runtimeId, prompt);
            }
          case SlashKind.prefill:
            _update(value.withNotice(outcome.notice).settled());
            if (outcome.text.isNotEmpty) onPrefill?.call(outcome.text);
          case SlashKind.alias:
            final target = outcome.target.trim();
            if (target.isEmpty || depth >= 3) {
              final output = outcome.text.trim();
              _update(
                value
                    .withNotice(
                      output.isEmpty ? 'That command points nowhere.' : output,
                    )
                    .settled(),
              );
              return;
            }
            final space = command.indexOf(' ');
            final arguments = space < 0 ? '' : command.substring(space);
            final next = target.startsWith('/') ? target : '/$target';
            await _slash(runtimeId, '$next$arguments', depth: depth + 1);
        }
    }
  }

  /// Stops the running turn.
  Future<void> stop() async {
    final runtimeId = _runtimeId;
    if (runtimeId == null || !value.running) return;
    final result = await _backend.interrupt(runtimeId);
    if (result case Err(:final failure)) {
      _update(value.withError(describe(failure)));
    }
  }

  /// What this conversation can switch to.
  Future<Result<ModelOptions>> modelOptions() =>
      _backend.modelOptions(runtimeId: _runtimeId);

  /// Switches this conversation's model. A switch Hermes wants confirmed
  /// changes nothing and comes back with `confirmRequired`, for the screen to
  /// ask and call again with [confirmed].
  Future<Result<ModelSwitch>> switchModel(
    String model,
    String provider, {
    required bool confirmed,
  }) async {
    final runtimeId = _runtimeId;
    if (runtimeId == null) {
      return const Err(
        IrisFailure(
          FailureKind.rejected,
          message: 'Send a message first: a new conversation has no model yet.',
        ),
      );
    }
    final result = await _backend.switchModel(

      model: model,
      provider: provider,
      confirmed: confirmed,
    );
    switch (result) {
      case Err(:final failure):
        _update(

        );
      case Ok(value: final change) when !change.confirmRequired:
        _update(

                    ? 'Switches to ${change.model} when this turn ends.'
                    : 'Now using ${change.model}.',
              ),
        );
      case Ok():
        break;
    }
    return result;
  }

  /// Answers [request] with [choice]. The card goes at once and comes back if
  /// the answer could not be sent, so the agent is never left waiting on a
  /// card nobody can see.
  Future<void> approve(ApprovalRequest request, String choice) async {
    _update(value.withoutApproval(request));

    if (result case Err(:final failure)) {
      _update(

            .withApproval(request)
            .withError('Could not send the answer: ${describe(failure)}'),
      );
    }
  }

  /// Answers one [question] of [request].
  Future<void> answer(

    String answer,
  ) async {
    final text = answer.trim();
    if (text.isEmpty) return;
    _update(value.withoutQuestion(request, question));
    final result = await _backend.answerClarify(request, question, text);
    if (result case Err(:final failure)) {
      _update(
        value
            .withQuestion(request)
            .withError('Could not send the answer: ${describe(failure)}'),
      );
    }
  }

  /// What to say about [failure] in the transcript.
  static String describe(IrisFailure failure) => switch (failure.kind) {
    FailureKind.offline =>
      'Not connected to your agent. Iris reconnects on its own; try again in '
          'a moment.',
    FailureKind.timeout => 'Your agent did not answer in time.',
    _ => failure.message ?? 'Something went wrong (${failure.kind.name}).',
  };

  /// Creates the conversation behind a new chat. Null if that failed, after
  /// saying why in the transcript.
  Future<String?> _create() async {
    switch (await _backend.create()) {
      case Err(:final failure):
        _update(value.withError(describe(failure)));
        return null;
      case Ok(value: final created):
        _storedId = created.storedId;
        return _runtimeId = created.runtimeId;
    }
  }

    final id = event.sessionId;
    if (id.isEmpty || (id != _runtimeId && id != _storedId)) return;
    _update(value.apply(event));
  }

    if (!_disposed) value = next;
  }

    _disposed = true;
    unawaited(_subscription?.cancel());
    unawaited(_reconnects?.cancel());
    super.dispose();
  }
```

```dart
AgentState agentStateFor(TurnPhase turn) => switch (turn) {
  TurnPhase.idle => AgentState.idle,
  TurnPhase.thinking => AgentState.thinking,
  TurnPhase.streaming => AgentState.streaming,
  TurnPhase.working => AgentState.working,
  TurnPhase.waiting => AgentState.waiting,

class ChatScreen extends StatefulWidget {
  const ChatScreen({
    required this.backend,
    this.conversationId,
    this.title,

  });

  State<ChatScreen> createState() => _ChatScreenState();

class _ChatScreenState extends State<ChatScreen> {
  late final ChatController _chat = ChatController(
    widget.backend,
    conversationId: widget.conversationId,
    title: widget.title,
  );

  @override
  void initState() {
    super.initState();
    _chat.onPrefill = _prefill;
    _text.addListener(_watchForSlash);

    _text.dispose();
    super.dispose();

  void _watchForSlash() {
    if (_text.text.startsWith('/')) unawaited(_chat.loadCommands());

    _text.value = TextEditingValue(
      text: text,
      selection: TextSelection.collapsed(offset: text.length),
    );

    _text.clear();
    unawaited(_chat.send(text));
```

```dart
class _ConversationList extends StatelessWidget {
  const _ConversationList({
    required this.conversations,
    required this.more,
    required this.loadingMore,
    required this.onOpen,
    required this.onMore,
    required this.onRetry,
  });

  final AsyncValue<ConversationPage?> conversations;
  final List<ConversationSummary> more;
  final bool loadingMore;
  final ValueChanged<ConversationSummary>? onOpen;

  /// Loads the next page from an offset; null when none can load.
  final ValueChanged<int>? onMore;
  final VoidCallback onRetry;

  static String? _subtitle(ConversationSummary conversation, DateTime now) {
    final parts = [
      if (conversation.startedAt case final at?) relativeTime(at, now),
      ?(conversation.source == 'desktop' ? null : conversation.source),
      if (conversation.messageCount > 0)
        '${conversation.messageCount} messages',
    ];
    return parts.isEmpty ? null : parts.join(' · ');
  }

  @override
  Widget build(BuildContext context) {
    final gutter = context.window.gutter;
    final page = conversations.value;
    if (page == null) {
      if (conversations.error case final error?) {
        return IrisEmptyState(
          title: 'Could not load conversations',
          message: error is IrisFailure
              ? error.message ?? error.kind.name
              : '$error',
          action: IrisButton(label: 'Try again', onPressed: onRetry),
        );
      }
      // Loading, or waiting for the link: placeholders where rows will be.
      return ListView(
        padding: EdgeInsets.symmetric(
          horizontal: gutter,
          vertical: IrisSpace.md,
        ),
        children: [
          for (var i = 0; i < 6; i++) ...[
            const IrisSkeleton(width: 220, height: 16),
            const SizedBox(height: IrisSpace.xs),
            const IrisSkeleton(width: 120, height: 12),
            const SizedBox(height: IrisSpace.lg),
          ],
        ],
      );
    }
    final list = [...page.items, ...more];
    if (list.isEmpty) {
      return const IrisEmptyState(
        title: 'No conversations yet',
        message:
            'Start one below. It will show here and in every other '
            'client of this agent.',
      );
    }
    final hasMore = list.length < page.total;
    final now = DateTime.now();
    final open = onOpen;
    final next = onMore;
    return ListView.builder(
      padding: EdgeInsets.symmetric(
        horizontal: gutter - IrisSpace.md,
        vertical: IrisSpace.sm,
      ),
      itemCount: list.length + (hasMore ? 1 : 0),
      itemBuilder: (context, index) {
        if (index == list.length) {
          return Padding(
            padding: const EdgeInsets.symmetric(vertical: IrisSpace.md),
            child: Center(
              child: IrisButton(
                label: 'Show more',
                tone: IrisButtonTone.ghost,
                busy: loadingMore,
                onPressed: next == null ? null : () => next(list.length),
              ),
            ),
          );
        }
        final conversation = list[index];
        return IrisListRow(
          key: ValueKey(conversation.id),
          title: conversation.title,
          subtitle: _subtitle(conversation, now),
          onTap: open == null ? null : () => open(conversation),
        );
      },
    );
  }
}
```
