# Phase 8 — Live voice mode Implementation Plan

> **For agentic workers:** execute with superpowers:executing-plans, inline, following
> `2026-10-19-phase8-run.md` (segments, model changes, the log). Never spawn subagents. Steps use checkbox (`- [ ]`)
> syntax for tracking.

**Goal:** a live voice conversation on any chat, on chained and GPT-Live Hermes servers, with the voice orb as the
microphone, a call that only starts once STT, the agent and TTS have answered, and voice settings that write the
server's voice.

**Architecture:** `lib/data/voice/` holds the wire (REST, two audio sockets, the GPT-Live session) behind a
`VoiceBackend` interface with dashboard and demo implementations. `lib/features/voice/` holds pure logic (levels,
speech detection, barge-in, spoken matching), the platform audio seams (mic, playback, audio session, foreground
service), one `VoiceCall` state machine with two engines (chained, GPT-Live), and the screens. The chat stays the owner
of the conversation: the call submits through `ChatController` and reads its state.

**Tech Stack:** Flutter (Dart 3.11), Riverpod 3 (hand-written providers), `record` 6.2.1 (PCM stream), new:
`audio_session`, a PCM player, a file player, `flutter_webrtc`, a foreground-service package, and `permission_handler`
(Task 4, for opening app settings and, in Task 10, the notification permission). Each is chosen and pinned in the task
that first needs it.

**Spec:** `docs/superpowers/specs/2026-10-19-phase8-design.md`. **Design:** `design/Iris Phase 4.dc.html` and
`design/iris-voice.js` (read the frame you are building; the design is the source of truth for sizes, colours, motion
numbers and copy).

## Global Constraints

- Branch `feat/phase8-voice`. Commits under the user's name only: no `Co-Authored-By`, no `Claude-Session` line. Add files by
  name; never `git add -A`; never commit `android/gradle.properties` or `store/screenshots/`.
- Every task ends with `flutter analyze` printing `No issues found!` and the task's tests passing; the last task of each
  segment also runs the full `flutter test` (excluding `--tags live`).
- New dependencies: pin exact versions (as `record: 6.2.1` is), each at least two weeks old, chosen in the task that
  first needs it; record the choice and version in the log. Prefer packages with Android and iOS support only.
- Never call `GET /api/audio/voice-config` (it returns provider keys). Never log PCM, transcripts, tickets or URLs with
  `?ticket=` unredacted (`IrisLog.redact`).
- Every audio route takes `?profile=<active profile>`, as `DashboardChat._scoped` does. Every audio socket gets a fresh
  ticket from `ServerConnection.auth.mintTicket()` and `accessHeadersFor(uri)`.
- Server tuning comes from `VoiceTuning` (Task 1); no other file hard-codes 200 / 3.0 / 120 / 0.5 / 3.0 / "stop".
- Copy is the design's, British spelling, no raw error codes in a primary line. GPT-Live call header:
  `VOICE · GPT-LIVE · OPENAI`; chained: `VOICE · {server label uppercased}`.
- Colours: palette roles only. The voice orb's mode colours are added once to `palette.dart` (dark and light, from
  `design/iris-voice.js` `DK`/`LT`); no widget holds a hex value. Contrast tests are never loosened.
- Reduced motion: every new animation has an O2/instant alternative; under `disableAnimations` no continuous ticker
  runs.
- 44 pt targets (56 pt call controls); no overflow at 320 pt wide or 200% text on any new surface.
- Hermes is slow: live tests that wait for a reply allow at least 240 s.

## Review Focus

1. **A second call started while one is ending** (double-tap the voice button, End then Call again fast): exactly one
   mic capture, one speak-stream and one foreground service exist. Test in Task 7 (`two starts leave one capture`).
2. **The profile or server changes, or the chat is popped, mid-call:** the call ends cleanly, the service stops, no
   socket stays open. Test in Task 11 (`popping the chat ends the call`).
3. **A reply with no speakable text** (only a tool call, or only code): Iris says nothing rather than hanging in
   speaking; the call returns to listening. Test in Task 7 (`empty reply returns to listening`).
4. **The server's `stop_phrases` is `[]` or a bare string; `silence_duration` is a string like "2"**: parsed like
   Hermes does (Desktop's `voice-prefs.ts`), never crashing. Test in Task 1 (`tuning tolerates odd values`).
5. **Permission revoked between calls** (mic denied in system settings while Iris is backgrounded): the next call shows
   A3b instead of preflighting. Test in Task 4 (`revoked permission shows the denied sheet`).
