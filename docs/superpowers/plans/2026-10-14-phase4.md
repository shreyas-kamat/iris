# Phase 4 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or
> superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Close the gaps in Iris's everyday loop. Remember the theme and profile, answer sudo and secret prompts,
steer and retry turns, rename, archive and search conversations, highlight code, and show the context window and
provider usage. Every surface follows the Iris design language.

**Architecture:**
- Data first. A Drift `Preferences` table, new `ChatBackend` methods, and pure parsers into new view values.
- Then state. `ChatState.apply` and `ChatController` gain steer, retry, input prompts and context.
- Then design components: `IrisRing`, `IrisToast`, `IrisCodeColors`, and secret and trailing support in
  `IrisField`.
- Then the screens: the composer, the chat screen, home (usage strip, search, row actions, Archived) and Settings
  (usage on home).
- Every screen reads palette roles and moves on the named springs.

**Tech stack:** Flutter (Dart `^3.11.4`), Riverpod 3 (hand-written providers), Drift, Dio, `markdown`, and a new
`re_highlight: ^0.0.3`.

**Spec:** `docs/superpowers/specs/2026-10-14-phase4-design.md`. Read it before starting. It records what the
server was probed to send, and the UI and motion table that every screen task follows.

## Global Constraints

- Branch `feat/phase4`. Commit after every task with a conventional message (`feat(chat): …`, `test(…): …`).
  **No `Co-Authored-By` trailer and no Claude attribution.** The user's standing rule overrides the older design
  plan's instruction. Don't push.
- Invoke the `flutter` skill before starting, and follow its verification loop.
- After **every** task, `flutter analyze` must report 0 issues and `flutter test` must pass. Live tests skip
  themselves unless run with `--tags live --run-skipped` or `--tags live_write --run-skipped`.
- Match the surrounding code:
  - library doc comments, and comments that say *why*
  - `context.palette`, `context.type`, `context.iris`
  - the `IrisSpace`, `IrisRadius`, `IrisStroke` and `IrisSize` tokens
  - `IrisPressable` for every tap
  - `IrisSprings` for motion through space, and `IrisDurations` with `IrisCurves` for changes of appearance
  - `IrisHaptics` named by meaning
- **No hex values in widgets.** Read palette roles, and derive new colours from them.
- **Reduced motion:** when `MediaQuery.disableAnimationsOf(context)` (`context.reduceMotion`) is true, every
  animation jumps to its end state and no ticker runs. Tests use `disableAnimations: true`
  (`test/support/harness.dart`), so `pumpAndSettle` must settle.
- Nothing throws past `lib/data`. Data methods return `Result<T>`.
- **Riverpod 3:** in a non-widget test, call `container.listen(p, (_, _) {})` before awaiting `p.future`, or the
  provider is paused and the await hangs.
- **Secrets:** a sudo or secret value is never stored in state, never logged, and never kept in a widget after
  it's sent.
- Never weaken a test to make it pass. Contrast tests are never loosened; adjust the colour instead.
- Tap targets are at least `IrisSize.minTapTarget` (44). Every icon-only control has a semantics label.

## Review Focus

These inputs and failure modes are implied by the spec but easy to miss. Each one is pinned by a test in the
named task.

1. **Slash text during a run, and a steer that can't be delivered.** Typing `/model` during a run must neither
   steer nor send. A steer that fails or is rejected must come back to the composer rather than vanish. Tested in
   Task 5 (`slash text during a run neither steers nor sends`, `a steer that fails to send comes back to the
   composer`) and Task 7 (`a slash command offers no steer`).
2. **A sudo or secret prompt answered after the socket dropped.** `answerInput` gets `false` from
   `replyToServerRequest`. The card must come back with an error, and the typed value must not stay anywhere.
   Tested in Task 4 (`answering an input without a live socket fails offline`) and Task 5
   (`a failed input answer brings the card back without the value`).
3. **A remembered profile that the server no longer has.** It must fall back to `default` and forget the key, not
   show an empty list forever. Tested in Task 2 (`a remembered profile the server lacks falls back`).
4. **A usage window with `used_percent` above 100, or a window or account without a label.** The bar clamps to
   full, the caption says "0% left", and labels fall back. Tested in Task 3
   (`usage clamps and fills in missing labels`).
5. **A search snippet with an unclosed `>>>` marker, or a row without a `session_id`.** It renders without crashing
   and the row is dropped. Tested in Task 3 (`snippets survive broken markers` and `search drops rows without a
   session id`).

```dart
/// Settings that outlive a launch.
///
/// Read once before the first frame (see `main.dart`), so the theme is right
/// on the very first paint, then written through as the person changes
/// things. A failed write is logged and forgotten: a setting that does not
/// stick is a small annoyance, and must never block the screen it was changed
/// on.
library;

import 'package:drift/drift.dart';

import '../../core/logging.dart';
import '../db/database.dart';

/// `(scope, key)`. The scope is `''` for app-wide settings, else a server id.
typedef PreferenceKey = (String scope, String key);

/// The keys Iris stores, so a typo is a compile error rather than a setting
/// that silently never loads.
abstract final class PreferenceKeys {
  static const skin = 'theme.skin';
  static const mode = 'theme.mode';
  static const followServerSkin = 'theme.followServerSkin';

  /// Per server: the profile home shows.
  static const profile = 'profile';

  /// Per server: a JSON list of provider slugs, `@profile` meaning the
  /// active profile's own provider.
  static const usageProviders = 'usage.providers';
}

abstract interface class PreferencesStore {
  Future<Map<PreferenceKey, String>> loadAll();

  /// Stores [value] under [scope] and [key], or removes the key when null.
  Future<void> write(String scope, String key, String? value);
}

final class DriftPreferencesStore implements PreferencesStore {
  DriftPreferencesStore(this._db);

  final IrisDatabase _db;
  static const _log = IrisLog('prefs');

  @override
  Future<Map<PreferenceKey, String>> loadAll() async {
    final rows = await _db.select(_db.preferences).get();
    return {for (final row in rows) (row.scope, row.key): row.value};
  }

  @override
  Future<void> write(String scope, String key, String? value) async {
    try {
      if (value == null) {
        await (_db.delete(_db.preferences)
              ..where((row) => row.scope.equals(scope) & row.key.equals(key)))
            .go();
      } else {
        await _db
            .into(_db.preferences)
            .insertOnConflictUpdate(
              PreferencesCompanion.insert(scope: scope, key: key, value: value),
            );
      }
    } on Object catch (error) {
      _log.warn('could not save $key', data: '$error');
    }
  }
}

/// Keeps settings in memory only. The default when no database is wired, so
/// tests and previews never need one.
final class MemoryPreferencesStore implements PreferencesStore {
  final Map<PreferenceKey, String> values = {};

  @override
  Future<Map<PreferenceKey, String>> loadAll() async => Map.of(values);

  @override
  Future<void> write(String scope, String key, String? value) async {
    if (value == null) {
      values.remove((scope, key));
    } else {
      values[(scope, key)] = value;
    }
  }
}
```

```dart
/// The person's saved choices, as providers.
///
/// [initialPreferencesProvider] is the snapshot `main` read before the first
/// frame; [preferencesProvider] is the live copy every change goes through,
/// so a value set now is what the next rebuild reads, and the store is
/// written behind it.
library;

import 'dart:async';

import 'package:flutter_riverpod/flutter_riverpod.dart';

import '../data/prefs/preferences_store.dart';

/// Where choices are written. In memory unless `main` wires the database, so
/// tests and goldens never need one.
final preferencesStoreProvider = Provider<PreferencesStore>(
  (ref) => MemoryPreferencesStore(),
);

/// What was saved when the app started.
final initialPreferencesProvider = Provider<Map<PreferenceKey, String>>(
  (ref) => const {},
);

final preferencesProvider =
    NotifierProvider<PreferencesController, Map<PreferenceKey, String>>(
      PreferencesController.new,
    );

class PreferencesController extends Notifier<Map<PreferenceKey, String>> {
  @override
  Map<PreferenceKey, String> build() => ref.watch(initialPreferencesProvider);

  String? get(String scope, String key) => state[(scope, key)];

  /// Saves [value], or forgets the key when it is null.
  void set(String scope, String key, String? value) {
    if (state[(scope, key)] == value) return;
    final next = Map.of(state);
    if (value == null) {
      next.remove((scope, key));
    } else {
      next[(scope, key)] = value;
    }
    state = next;
    unawaited(ref.read(preferencesStoreProvider).write(scope, key, value));
  }
}
```

```dart
/// The agent profile the conversation list and new chats belong to.
///
/// Remembered per server: a different server has different profiles, so each
/// starts at its own last choice, or its default.
final activeProfileProvider = NotifierProvider<ActiveProfile, String>(
  ActiveProfile.new,
);

class ActiveProfile extends Notifier<String> {
  @override
  String build() {
    final server = ref.watch(activeServerIdProvider);
    if (server == null) return 'default';
    return ref.read(preferencesProvider)[(server, PreferenceKeys.profile)] ??
        'default';
  }

  void select(String profile) {
    state = profile;
    final server = ref.read(activeServerIdProvider);
    if (server == null) return;
    // The default is stored as no key at all, so a server whose default is
    // renamed still opens on its default.
    ref
        .read(preferencesProvider.notifier)
        .set(
          server,
          PreferenceKeys.profile,
          profile == 'default' ? null : profile,
        );
  }
}
```

```dart
/// What kind of value an input prompt wants.
enum InputKind { sudo, secret }

/// The agent needs a value typed in that must never be shown or kept: a sudo
/// password, an API key. Answered once, then forgotten.
@immutable
final class InputRequest {
  const InputRequest({
    required this.requestId,
    required this.sessionId,
    required this.kind,
    this.command = '',
    this.envVar = '',
    this.prompt = '',
  });

  /// The `srq-…` server request the answer is addressed to.
  final String requestId;
  final String sessionId;
  final InputKind kind;

  /// sudo: the command that needs the password, as Hermes redacted it.
  final String command;

  /// secret: the environment variable the value is stored under.
  final String envVar;

  /// secret: what Hermes says it needs.
  final String prompt;

  /// The card's headline.
  String get title => switch (kind) {
    InputKind.sudo => 'Hermes needs your sudo password',
    InputKind.secret when prompt.isNotEmpty => prompt,
    InputKind.secret when envVar.isNotEmpty =>
      'Hermes needs a value for $envVar',
    InputKind.secret => 'Hermes needs a secret value',
  };
}

/// How full the conversation's context window is.
@immutable
final class ContextUsage {
  const ContextUsage({required this.percent, this.used, this.max});

  /// 0 to 100.
  final double percent;

  /// Tokens in the window and its size, when the gateway says.
  final int? used;
  final int? max;
}

/// One subscription window: a five-hour session, a week.
@immutable
final class UsageWindow {
  const UsageWindow({
    required this.label,
    required this.usedPercent,
    this.resetsAt,
    this.accountScoped = true,
  });

  final String label;

  /// 0 to 100.
  final double usedPercent;
  final DateTime? resetsAt;

  /// False for a window that caps one model family only, which never means
  /// the whole account is out.
  final bool accountScoped;

  double get leftPercent => (100 - usedPercent).clamp(0, 100).toDouble();
}

enum UsageAccountState { ready, limited, unavailable, unknown }

/// One login of a provider that has several.
@immutable
final class UsageAccount {
  const UsageAccount({
    required this.label,
    required this.state,
    this.windows = const [],
    this.resetsAt,
  });

  final String label;
  final UsageAccountState state;
  final List<UsageWindow> windows;
  final DateTime? resetsAt;
}

/// How much of a provider's subscription is spent.
@immutable
final class ProviderUsage {
  const ProviderUsage({this.windows = const [], this.accounts = const []});

  /// For a single-account provider.
  final List<UsageWindow> windows;

  /// For a provider with a pool of accounts, one each.
  final List<UsageAccount> accounts;

  /// The window closest to its limit, which is what a collapsed row shows. For
  /// a pool, the best account's tightest window: the pool keeps working while
  /// any account does.
  UsageWindow? get tightest {
    UsageWindow? worst(List<UsageWindow> windows) => windows.isEmpty
        ? null
        : windows.reduce((a, b) => b.usedPercent > a.usedPercent ? b : a);
    if (windows.isNotEmpty) return worst(windows);
    UsageWindow? best;
    for (final account in accounts) {
      final candidate = worst(account.windows);
      if (candidate != null &&
          (best == null || candidate.usedPercent < best.usedPercent)) {
        best = candidate;
      }
    }
    return best;
  }
}

/// A piece of a search snippet, matched or not.
@immutable
final class SnippetRun {
  const SnippetRun(this.text, {this.matched = false});

  final String text;
  final bool matched;
}

    required this.storedId,
    required this.title,
    this.snippet = const [],
    this.lastActive,
    this.archived = false,
    this.messageCount = 0,

  final String title;

  /// The best matching message, with the matched words marked.
  final List<SnippetRun> snippet;
  final DateTime? lastActive;
  final bool archived;
  final int messageCount;
}
```

```dart
/// Reads the context window, provider usage and search rows.
///
/// Shapes verified on the user's server on 2026-10-14; see
/// `docs/superpowers/specs/2026-10-14-phase4-design.md`.
library;

import '../../core/json.dart';
import 'chat_models.dart';
import 'history_parser.dart';

abstract final class UsageParser {
  /// Context fill from `session.info`, a `session.usage` event or a resume's
  /// `info`, whose numbers may sit under `usage`. Null when there are no
  /// usable numbers, which a lazy, idle session never has. That is not the
  /// same as an empty window.
  static ContextUsage? context(Json json) {
    final source =
        json['context_percent'].hasValue || json['context_max'].hasValue
        ? json
        : json['usage'];
    final used = source['context_used'].intOrNull;
    final max = source['context_max'].intOrNull;
    var percent = source['context_percent'].doubleOrNull;
    // Hermes has sent both a fraction and a percentage.
    if (percent != null && percent > 0 && percent <= 1) percent *= 100;
    if ((percent == null || percent <= 0) &&
        used != null &&
        max != null &&
        max > 0) {
      percent = used / max * 100;
    }
    if (percent == null) return null;
    if (percent <= 0 && (max == null || max <= 0)) return null;
    return ContextUsage(
      percent: percent.clamp(0, 100).toDouble(),
      used: used,
      max: max == null || max <= 0 ? null : max,
    );
  }

  /// A `model.options` provider row's `usage`.
  static ProviderUsage? providerUsage(Json usage) {
    if (!usage.isMap) return null;
    final windows = _windows(usage['windows']);
    final accounts = [for (final row in usage['accounts'].list) _account(row)];
    if (windows.isEmpty && accounts.isEmpty) return null;
    return ProviderUsage(windows: windows, accounts: accounts);
  }

  static List<UsageWindow> _windows(Json list) => [
    for (final row in list.list)
      if (row['used_percent'].doubleOrNull case final used?)
        UsageWindow(
          label: HistoryParser.firstText(row, const ['label']) ?? 'Usage',
          usedPercent: used.clamp(0, 100).toDouble(),
          resetsAt: row['resets_at'].dateTimeOrNull,
          accountScoped: row['scope'].string('account') != 'model',
        ),
  ];

  static UsageAccount _account(Json row) => UsageAccount(
    label: HistoryParser.firstText(row, const ['label']) ?? 'Account',
    state:
        UsageAccountState.values.asNameMap()[row['state'].string()] ??
        UsageAccountState.unknown,
    windows: _windows(row['windows']),
    resetsAt: row['resets_at'].dateTimeOrNull,
  );

  /// `GET /api/sessions/search`: one row per matching *message*, folded to
  /// one hit per conversation, keeping the server's order and each
  /// conversation's first snippet. A row's `id` may be a message id, so only
  /// `session_id` names the conversation.
  static List<SearchHit> searchHits(Json body) {
    final seen = <String>{};
    final hits = <SearchHit>[];
    for (final row in body['results'].list) {
      final id = HistoryParser.firstText(row, const ['session_id']);
      if (id == null || !seen.add(id)) continue;
      hits.add(
        SearchHit(
          storedId: id,
          title:
              HistoryParser.firstText(row, const ['title', 'preview']) ??
              'Untitled conversation',
          snippet: snippet(row['snippet'].string()),
          lastActive: row.any(const [
            'last_active',
            'session_started',
            'started_at',
          ]).dateTimeOrNull,
          archived: row['archived'].boolean(),
          messageCount: row['message_count'].integer(),
        ),
      );
    }
    return hits;
  }

  /// Hermes marks matched words `>>>like this<<<`. The text is flattened to
  /// one line. A marker left open marks nothing, but still separates the text
  /// before it from the text after; an empty `>>><<<` pair joins its sides.
  static List<SnippetRun> snippet(String raw) {
    final runs = <SnippetRun>[];
    var rest = raw.replaceAll(RegExp(r'\s+'), ' ');
    var plain = '';
    void flush() {
      if (plain.isNotEmpty) runs.add(SnippetRun(plain));
      plain = '';
    }

    while (rest.isNotEmpty) {
      final open = rest.indexOf('>>>');
      if (open < 0) {
        plain += rest;
        break;
      }
      plain += rest.substring(0, open);
      final close = rest.indexOf('<<<', open + 3);
      if (close < 0) {
        // An unclosed marker marks nothing, but still separates the text.
        flush();
        plain = rest.substring(open + 3);
        break;
      }
      final word = rest.substring(open + 3, close);
      if (word.isNotEmpty) {
        flush();
        runs.add(SnippetRun(word, matched: true));
      }
      rest = rest.substring(close + 3);
    }
    flush();
    return runs;
  }
}
```

```dart
  /// The context window from an event that carries it: `session.info`, or
  /// the `session.usage` the gateway sends after each turn. Separate from
  /// [fromEvent] because one `session.info` also reports the model.
  static ContextChanged? contextFromEvent(RpcEvent event) {
    if (event.type != 'session.info' && event.type != 'session.usage') {
      return null;
    }
    final usage = UsageParser.context(event.payload);
    return usage == null ? null : ContextChanged(event.sessionId ?? '', usage);
  }

  /// A sudo or secret request. Null without a session, which nothing could
  /// answer.
  static InputRequest? parseInput(RpcServerRequest request) {
    final session = request.params['session_id'].string().trim();
    if (session.isEmpty || request.id.isEmpty) return null;
    String text(String key) => request.params[key].string().trim();
    return InputRequest(
      requestId: request.id,
      sessionId: session,
      kind: request.method == 'sudo' ? InputKind.sudo : InputKind.secret,
      command: text('command'),
      envVar: text('env_var'),
      prompt: text('prompt'),
    );
  }
```

```dart
    if (runtimeId == null) return;

    if (_disposed) return;
    switch (result) {
      case Ok(value: SteerOutcome.accepted):

      case Ok() when !value.running:
        // The turn ended while the steer was on its way: it becomes a prompt.
        _update(value.withUserTurn(text));
        await _submit(runtimeId, text);
      case Ok():

  /// exchange itself, so once the new turn settles the newest page is read
  /// again, and the transcript shows what Hermes now holds rather than the
  /// failure and the retry side by side.
  Future<void> retry() async {
    final runtimeId = _runtimeId;
    if (runtimeId == null || value.running || value.retrying) return;
    _update(value.copyWith(retrying: true, turn: TurnPhase.thinking));
    await _slash(runtimeId, '/retry', depth: 0);
    if (_disposed) return;
    if (value.running) {
      _reloadWhenIdle = true;
    } else {
      await _reloadNewest();

    final storedId = _storedId;
    if (storedId == null) return;
    final page = await _backend.history(storedId);
    if (_disposed) return;
    _update(switch (page) {
      Ok(value: final newest) => value.withNewestPage(
        newest.items,
        newest.earlier,
      ),
      Err() => value.copyWith(retrying: false),
    });

  /// goes at once. The answer is passed straight to the backend and kept
  /// nowhere, not even in the notice that records it was sent.
  Future<void> answerInput(InputRequest request, String answer) async {

                : 'Sent.',
          ),
        );

          value
              .withInput(request)
              .withError('Could not send that: ${describe(failure)}'),
```

```dart
class _RingPainter extends CustomPainter {
  _RingPainter({required this.fill, required this.track, required this.tint});

  final double fill;
  final Color track;
  final Color tint;

  @override
  void paint(Canvas canvas, Size size) {
    const stroke = IrisStroke.ring;
    final rect = (Offset.zero & size).deflate(stroke / 2);
    final paint = Paint()
      ..style = PaintingStyle.stroke
      ..strokeWidth = stroke;
    canvas.drawArc(rect, 0, math.pi * 2, false, paint..color = track);
    if (fill <= 0) return;
    canvas.drawArc(
      rect,
      -math.pi / 2,
      math.pi * 2 * fill,
      false,
      paint
        ..color = tint
        ..strokeCap = StrokeCap.round,
    );
  }

  @override
  bool shouldRepaint(_RingPainter old) =>
      old.fill != fill || old.track != track || old.tint != tint;
}
```

```dart
  BuildContext context, {
  required String message,
  String? actionLabel,
  VoidCallback? onAction,
  double bottomInset = 104,

      message: message,
      actionLabel: actionLabel,
      onAction: onAction,
      bottomInset: bottomInset,
      onDone: dismiss,

  );

  overlay.insert(entry);
```

```dart
///
/// Code blocks belong to the skin rather than to a borrowed editor theme: the
/// roles come from the agent-state hues every skin already tunes, and each is
/// nudged toward ink until it clears AA on the code well. That nudge is why
/// the contrast test can never fail for a new skin.
library;

import 'package:flutter/widgets.dart';

import 'palette.dart';

@immutable
final class IrisCodeColors {
  const IrisCodeColors({
    required this.plain,
    required this.keyword,
    required this.string,
    required this.number,
    required this.comment,
    required this.title,
    required this.type,
    required this.attr,
    required this.meta,
    required this.addition,
    required this.deletion,
  });

  static final Expando<IrisCodeColors> _cache = Expando();

  /// The code colours for [palette], computed once per palette.
  static IrisCodeColors of(IrisPalette palette) =>
      _cache[palette] ??= _derive(palette);

  static IrisCodeColors _derive(IrisPalette p) {
    final well = p.surfaceSunken;
    Color legible(Color color) => _legible(color, toward: p.ink, on: well);
    return IrisCodeColors(
      plain: p.ink,
      keyword: legible(p.colorFor(AgentState.thinking)),
      string: legible(p.colorFor(AgentState.done)),
      number: legible(p.colorFor(AgentState.working)),
      comment: legible(p.inkMuted),
      title: legible(p.accent),
      type: legible(p.colorFor(AgentState.streaming)),
      attr: legible(p.colorFor(AgentState.waiting)),
      meta: legible(p.inkMuted),
      addition: legible(p.colorFor(AgentState.done)),
      deletion: legible(p.colorFor(AgentState.failed)),
    );

  /// [color], moved toward [toward] in small steps until it reaches 4.5:1 on
  /// [on]. [toward] is ink, which passes on every surface, so this ends.
  static Color _legible(Color color, {required Color toward, required Color on}) {
    var current = color;
    for (var step = 1; step <= 10 && _contrast(current, on) < 4.5; step++) {
      current = Color.lerp(color, toward, step / 10)!;
    }
    return current;

    final la = a.computeLuminance();
    final lb = b.computeLuminance();
    final hi = la > lb ? la : lb;
    final lo = la > lb ? lb : la;
    return (hi + 0.05) / (lo + 0.05);
```

```dart
  final digits = value.abs().toString();

  for (var i = 0; i < digits.length; i++) {
```

```dart
/// A sudo password or a secret the agent needs. The field is masked, with an
/// eye to check what was typed; nothing typed outlives the card. The answer is
/// handed over and the field cleared in the same moment.
class InputCard extends StatefulWidget {
  const InputCard({required this.request, required this.onAnswer, super.key});

  final InputRequest request;

  /// Called with the value, or `''` to skip.
  final Future<void> Function(String value) onAnswer;

  @override
  State<InputCard> createState() => _InputCardState();
}

class _InputCardState extends State<InputCard> {
  final _text = TextEditingController();
  bool _revealed = false;
  bool _sending = false;

  @override
  void initState() {
    super.initState();
    // Something is waiting on the person; the phone says so once.
    unawaited(IrisHaptics.gate());
  }

  @override
  void dispose() {
    _text.dispose();
    super.dispose();
  }

  Future<void> _send(String value) async {
    if (_sending) return;
    if (value.isNotEmpty) unawaited(IrisHaptics.commit());
    setState(() => _sending = true);
    // Cleared before the answer leaves, so the value lives in no widget
    // while the request is in flight.
    _text.clear();
    await widget.onAnswer(value);
    if (mounted) setState(() => _sending = false);
  }

  @override
  Widget build(BuildContext context) {
    final theme = context.iris;
    final palette = theme.palette;
    final waiting = palette.colorFor(AgentState.waiting);
    final request = widget.request;
    final isSudo = request.kind == InputKind.sudo;
    final noun = isSudo ? 'password' : 'value';
    return IrisCard(
      accent: waiting,
      child: Column(
        crossAxisAlignment: CrossAxisAlignment.start,
        children: [
          Row(
            children: [
```

```dart
/// The longest block worth highlighting. Past this the parse is slow enough
/// to drop frames, and a block that long is read by scrolling, not by colour.
const int maxHighlightLength = 20000;

final Highlight _highlighter = Highlight()
  ..registerLanguages(builtinAllLanguages);

/// The names people write on fences, mapped to the grammar's.
const _aliases = {
  'sh': 'bash',
  'zsh': 'bash',
  'shell': 'bash',
  'console': 'bash',
  'py': 'python',
  'ts': 'typescript',
  'js': 'javascript',
  'yml': 'yaml',
  'md': 'markdown',
  'kt': 'kotlin',
  'rs': 'rust',
  'golang': 'go',
};

/// The grammar for a fence's language, or null when there is none. There is
/// no guessing: detection is slow and often wrong, and a wrongly coloured
/// block reads worse than a plain one.
String? highlightLanguage(String? fence) {
  final name = fence?.trim().toLowerCase();
  if (name == null || name.isEmpty) return null;
  final resolved = _aliases[name] ?? name;
  return _highlighter.getLanguage(resolved) == null ? null : resolved;
}

/// Highlighted spans, by palette, language and code. A transcript rebuilds
/// often, and the parse is the expensive part.
final Map<(IrisCodeColors, String, String), TextSpan> _spanCache = {};

TextSpan? _highlighted(String code, String? fence, IrisCodeColors colors) {
  final language = highlightLanguage(fence);
  if (language == null || code.length > maxHighlightLength) return null;
  final key = (colors, language, code);
  final cached = _spanCache[key];
  if (cached != null) return cached;
  final renderer = TextSpanRenderer(null, colors.theme);
  _highlighter.highlight(code: code, language: language).render(renderer);
  final span = renderer.span;
  if (span == null) return null;
  // Bounded, so a long session does not hold every block it ever showed.
  if (_spanCache.length > 200) _spanCache.clear();
  return _spanCache[key] = span;
}
```

```dart
/// How long until [time], for "resets in 2h 36m". A moment already past, or
/// less than a minute away, reads as "now".
String timeUntil(DateTime time, DateTime now) {
  final left = time.difference(now);
  if (left.inMinutes < 1) return 'now';
  if (left.inHours < 1) return 'in ${left.inMinutes}m';
  if (left.inDays < 1) return 'in ${left.inHours}h ${left.inMinutes % 60}m';
```

```dart
/// Which providers' subscription usage home shows, and what they report.
///
/// Usage comes from `model.options`, which reads a server-side cache and
/// starts a background fetch when the cache is cold, so a first ask can come
/// back empty and a second, a few seconds later, full. That second ask happens
/// once, here, not in a loop.
library;

import 'dart:convert';

import 'package:flutter/foundation.dart';
import 'package:flutter_riverpod/flutter_riverpod.dart';

import '../core/result.dart';
import '../data/chat/chat_models.dart';
import '../data/prefs/preferences_store.dart';
import '../data/rpc/dashboard_session.dart';
import 'preferences.dart';
import 'providers.dart';

/// Stands for the active profile's own provider in the saved list.
const usageFollowsProfile = '@profile';

final usageSelectionProvider = NotifierProvider<UsageSelection, List<String>>(
  UsageSelection.new,
);

/// The providers home shows, in order: Main, then Secondary, then any others.
class UsageSelection extends Notifier<List<String>> {
  static const fallback = [usageFollowsProfile];

  @override
  List<String> build() {
    final server = ref.watch(activeServerIdProvider);
    if (server == null) return fallback;
    final raw = ref.read(preferencesProvider)[(
      server,
      PreferenceKeys.usageProviders,
    )];
    if (raw == null) return fallback;
    try {
      final decoded = jsonDecode(raw);
      if (decoded is List) {
        final slugs = [
          for (final slug in decoded)
            if (slug is String && slug.isNotEmpty) slug,
        ];
        if (slugs.isNotEmpty) return slugs;
      }
    } on FormatException {
      // A damaged value is the default, not an error on screen.
    }
    return fallback;
  }

  void setAll(List<String> slugs) {
    final cleaned = <String>[];
    for (final slug in slugs) {
      if (slug.isNotEmpty && !cleaned.contains(slug)) cleaned.add(slug);
    }
    final next = cleaned.isEmpty ? fallback : cleaned;
    state = next;
    final server = ref.read(activeServerIdProvider);
    if (server == null) return;
    ref
        .read(preferencesProvider.notifier)
        .set(
          server,
          PreferenceKeys.usageProviders,
          listEquals(next, fallback) ? null : jsonEncode(next),
        );
  }
}

/// How long to wait before asking again when the gateway had no numbers yet.
final usageRetryDelayProvider = Provider<Duration>(
  (ref) => const Duration(seconds: 5),
);

/// The active profile's own provider, from `GET /api/profiles`, when known.
final _profileProviderSlug = Provider<String?>((ref) {
  final name = ref.watch(activeProfileProvider);
  final profiles = ref.watch(profilesProvider).value ?? const <AgentProfile>[];
  for (final profile in profiles) {
    if (profile.name == name) return profile.provider;
  }
  return null;
});

/// What the gateway reports about its providers, asked a second time when
/// the first answer had no usage for a signed-in provider.
final usageOptionsProvider = FutureProvider<ModelOptions?>((ref) async {
  final live = ref.watch(
    activeLinkProvider.select((link) => link.value?.phase == LinkPhase.live),
  );
  if (!live) return null;
  final delay = ref.watch(usageRetryDelayProvider);
  final chat = await ref.watch(activeChatProvider.future);
  if (chat == null) return null;
  final first = switch (await chat.modelOptions()) {
    Ok(:final value) => value,
    Err() => null,
  };
  if (first == null || !_cold(first)) return first;
  await Future<void>.delayed(delay);
  return switch (await chat.modelOptions()) {
    Ok(:final value) => value,
    Err() => first,
  };
});

/// No provider reports usage yet, though one is signed in: the cache was
/// cold, and the first ask started filling it.
bool _cold(ModelOptions options) =>
    options.providers.every((p) => p.usage == null) &&
    options.providers.any((p) => p.authenticated || p.isCurrent);

/// One provider row home shows.
@immutable
final class UsageRow {
  const UsageRow({required this.slug, required this.name, required this.usage});

  final String slug;
  final String name;
  final ProviderUsage usage;
}

/// The rows to show for [wanted], in order, without repeats, leaving out
/// providers that report no usage.
List<UsageRow> resolveUsageRows(
  List<String> wanted,
  ModelOptions options, {
  String? profileProvider,
}) {
  final bySlug = {for (final p in options.providers) p.slug: p};
  final seen = <String>{};
  final rows = <UsageRow>[];
  for (final entry in wanted) {
    final slug = entry == usageFollowsProfile
        ? (profileProvider ?? options.provider)
        : entry;
    if (slug == null || !seen.add(slug)) continue;
    final provider = bySlug[slug];
    final usage = provider?.usage;
    if (provider == null || usage == null) continue;
    rows.add(UsageRow(slug: slug, name: provider.name, usage: usage));
  }
  return rows;
}

/// The rows home shows.
final providerUsageProvider = Provider<AsyncValue<List<UsageRow>>>((ref) {
  final wanted = ref.watch(usageSelectionProvider);
  final profileProvider = ref.watch(_profileProviderSlug);
  return ref
      .watch(usageOptionsProvider)
      .whenData(
        (options) => options == null
            ? const <UsageRow>[]
            : resolveUsageRows(
                wanted,
                options,
                profileProvider: profileProvider,
              ),
      );
});
```

```dart
/// A row that slides out to the leading edge and folds its height when
/// [gone], and springs back when it is not, as it does when an archive is
/// undone. Kept in the tree while gone, so the undo has something to spring.
class Leaving extends StatelessWidget {
  const Leaving({required this.gone, required this.child, super.key});

  final bool gone;
  final Widget child;

  @override
  Widget build(BuildContext context) => SpringBuilder(
    value: gone ? 0 : 1,
    builder: (context, t, child) {
      final shown = t.clamp(0.0, 1.0);
      if (shown == 0) return const SizedBox(width: double.infinity);
      return ClipRect(
        child: Align(
          alignment: Alignment.topCenter,
          heightFactor: shown,
          child: Opacity(
            opacity: shown,
            child: Transform.translate(
              offset: Offset(-(1 - shown) * 48, 0),
              child: child,
            ),
          ),
        ),
      );
    },
    child: child,
  );
}
```

- [ ] **Step 2: Read-only live checks**

In `test/live/dashboard_live_test.dart`, add a test in the file's style (connect, start, `DashboardChat`), printing
shapes only:

```dart
  test(
    'usage, search and the archived list read cleanly',
    () async {
      final connection = ServerConnection.create(config, secrets: secrets);
      final session = DashboardSession(http: connection);
      final chat = DashboardChat(session);
      addTearDown(() async {
        await chat.dispose();
        await session.dispose();
        connection.close();
      });
      await session.start();

      // The usage cache may be cold on the first ask; the second finds it.
      await chat.modelOptions();
      await Future<void>.delayed(const Duration(seconds: 6));
      final options = (await chat.modelOptions()).valueOrNull!;
      final reporting = options.providers.where((p) => p.usage != null).toList();
      stdout.writeln('usage from: ${reporting.map((p) => '${p.slug}(${p.usage!.windows.length + p.usage!.accounts.length})')}');
      expect(reporting, isNotEmpty, reason: 'a signed-in subscription provider should report usage');

      final hits = (await chat.search('the')).valueOrNull!;
      stdout.writeln('search hits: ${hits.length}, titled: ${hits.where((h) => h.title.isNotEmpty).length}');
      expect(hits.map((h) => h.storedId).toSet().length, hits.length);

      final archived = await chat.archivedConversations(0);
      stdout.writeln('archived: ${archived.valueOrNull?.total ?? archived.failureOrNull?.kind}');
      expect(archived.isOk, isTrue);
    },
    timeout: const Timeout(Duration(minutes: 2)),
  );
```

Run: `flutter test --tags live --run-skipped test/live/dashboard_live_test.dart`
Expected: passes. Record the printed shapes in the device-pass document (Step 4).
