Frames only show fields the server sends. If a field is missing, its slot is left out, never filled in. Each phone’s note names the Phase 2 part it reuses.
DRAWN AS SENT Schedules · schedule.display if present, else schedule.expr, verbatim in a mono chip. Never translated. Job name · name, else the first line of prompt. Model and Deliver to rows only exist when set. Tasks · no due dates, no percent bars. Progress only as “n of m subtasks”. Elapsed comes from started_at, on Running cards only.
