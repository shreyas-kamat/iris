# App Store release candidate

Listing copy lives in `en-US/`. These files are local drafts, not an App Store Connect submission.
Version: **1.0.0 (1)**. Bundle ID: **com.iflotech.iris**. Suggested primary category: Productivity;
secondary: Utilities. No in-app purchases or Iris account. Confirm pricing and territory availability
in App Store Connect. Confirm seller/copyright ownership before entering those fields.

## Review notes to paste

Iris is an independent mobile client for a user-operated Hermes agent dashboard. It does not create
an Iris account, host an agent, sell digital services, or require an Iris subscription.

To explore without credentials, tap **Try the demo** on the first screen. The offline demo uses
sample data and scripted conversations; it sends nothing to a server. Open a sample conversation
and use its suggested prompts to see streamed replies, tool calls and approval prompts. Settings
contains **Leave demo**, appearance choices, the privacy policy and open-source licences.

The demo does not establish that all live features work. For a complete review, provide a dedicated
reachable HTTPS Hermes dashboard and credentials below in App Store Connect's private review fields.
Keep that server running during review, with non-sensitive sample data and configured voice support.
Do not use a personal or production server. No pairing hardware is required.

Server URL: [provide privately before submission]
Username/password or access credentials: [provide privately before submission]
Contact name, phone and email: [complete in App Store Connect]

Local-network permission connects to a dashboard on the user's own network. The microphone is used
only for dictation and voice calls. Background audio supports an active voice call. Ordinary voice
calls use the user's server; GPT-Live asks before sending audio directly to OpenAI. Available speech
providers depend on the dashboard. Public server addresses require HTTPS.

## Required before upload/submission

- Select the correct developer team in Xcode and create the bundle-ID/app record. Complete agreements,
  export compliance, content rights, availability, the current age-rating questionnaire, and review contact.
  Do not guess the age rating for an app with unrestricted agent-generated text and links.
- Follow `docs/release.md` to create a signed archive and validate it in Organizer. The unsigned archive
  is a compilation check and cannot be uploaded as the final distribution build.
- Verify privacy and support URLs in a browser. The local website policy includes voice/GPT-Live;
  ensure the deployed site contains the same current policy, rather than only returning an HTTP 200.
- Review App Privacy answers against actual server/provider retention. The developer runs no collection
  service and uses no analytics or tracking. That alone does not prove that third-party processing is
  exempt from disclosure: GPT-Live audio is sent directly to OpenAI. Confirm provider retention and
  applicable disclosure rules before selecting “Data Not Collected”. The app manifest currently declares
  no tracking/no collection; update it too if the final answers require collected data declarations.
- Inspect Xcode's aggregated privacy report for all embedded SDK manifests and required-reason APIs.
  The app's own native code does not declare required-reason API usage. An empty app API array does not
  certify all dependencies; check the final archive's SDK manifests.
- Test a signed release on physical iPhone and iPad: connect/authenticate; chat/approvals; files/photos;
  microphone and local-network permission allowed/denied; dictation; speaker/earpiece/Bluetooth;
  voice interruptions and background calls; GPT-Live accept/cancel. Test large text and reduced motion.
- Capture real simulator/device screenshots showing the app in use, using offline demo data. Supply
  the iPhone and iPad sizes App Store Connect requests (the app targets both). Include conversations,
  approvals and home; do not use only a welcome/login screen or submit golden-test images as screenshots.
  Keep server addresses and credentials out of screenshots. Screenshots are not generated by this draft.
- Keep the review server and credentials valid through review. The demo is partial; do not describe it
  as full coverage of live voice and server functionality. Request Apple's approval if relying solely
  on a demo instead of review credentials.
